# 稳定版指标口径

- 上市日 T0 = `time_periods.{gen}.end`；代际 = `series_group_logic` priority 裁决。
- N = (as-of − 主代际 T0).days + 1，各自窗口 [T0,T0+N)。对标截至 as-of 可观察天数不足时共同收窗并披露；对标未上市直接阻断。
- 零售锁单 = 用户车 COUNTD(order_number)，剔测试单、总部主理店、非零售。主键重复/空值阻断。
- 快照最新锁单日需覆盖 as-of；窗口内无记录日期无法证实为零时阻断，不补零。
- 小订池允许订单类型空白，其余过滤同零售；池 P = intention_payment_time<T0 的全部订单，包含配置预售开始日前记录并披露数量。
- 池锁单 K = 池内 lock_time<T0+N；池退款 R = 池内 intention_refund_time<T0+N。退款日期粒度不能解读为日内操作时点。
- 锁单事件率 r=K/P、退款事件率=R/P，两率不能当互斥状态相加。重叠 O 独立统计。旧 P−K−R 不再称待转化或剩余。
- 来源四类：ip<T0；T0≤ip<T0+1日；ip为空；ip≥T0+1日。均限窗口内零售锁单，四项和=总锁单。
- 日增=每日去重锁单；累计=日增累计和；边际差=主代际日增−对标日增。
- D1占比=D1/窗口累计；尾段日均=ΣD2..DN/(N−1)，N=1不输出。
- 池分解：(P主−P标)×r标 + P主×(r主−r标) = K主−K标。使用未舍入率计算，只在呈现时格式化。
- 来源差分解保留日后残余；四项来源差之和=总锁单差。无贡献占比、主次排序或因果推断。

不输出区域、门店、客群、配置、版本、PK、订单质量、未来需求指标。历史定义只在 Git 中保留。
