# 反模式与工程陷阱

来自一次真实研究（LS8Neo vs CM3 / LS8）的 37 轮返工记录，每条都对应一次用户纠偏或一次线上事故。

## 一、表达类（用户直接纠正过）

### 1. 自造品类名

❌ 把「非超广角方向盘」命名为「非基础款方向盘」
✅ 用 `config_attribute` 的 `Attribute` / `value` 原文；必须聚合时，在表注写明映射关系

### 2. 用派生指标替代直观差额

❌ 区域表只给「结构效应 = 占比差 × 总量」
✅ 主表给绝对差额（主车 − 对标）；分解只在归因时作辅表

### 3. 按差额排序导致省份消失

❌ 按 `|差额|` 取前 12 省 → 体量大但差额小的省（如湖北 +12）被挤掉
✅ 先按**主车体量**取前 N，再按需要排序展示

### 4. 差额只给数字

❌ 差额列是 `-227`
✅ 单元格内条形图：0 中线、按列归一、正负异色、数值随条显示

### 5. 顺序随幅度变化

❌ 每次重跑按 `|差值|` 重排 → 跨版本无法对照
✅ 维度顺序固定（与对应表格一致）

### 6. 补充表自造维度

❌ 补充表用「城市线级 一线」等自造行名
✅ 复用主表的行名、行序、列口径；只在表头加「（剔除 XX）」等限定

### 7. 同一维度堆多个近似指标

❌ 同时给「车主年龄中位数」「购车人年龄中位数」
✅ 一个维度一个口径（如车主年龄均值），并在方法文档说明选择理由

### 8. 概念误用：一线占比低 ≠ 更下沉

❌ 「剔除上海后一线占比更低 → 更下沉」
✅ 下沉程度看**三线及以下占比**；一线、二线、三线分别陈述

### 9. 一图多对象

❌ 三个车型塞进一张复合图
✅ 一个对象一张图；需要对照时用同构的多张图并列

### 10. 图与表重复

❌ 同一结论既有大表又有一张同信息图
✅ 保留信息密度更高的那一个；表格给精确值，图给形状

## 二、口径类

### 11. 混用「占比」与「绝对额」

- 看结构差异用占比；看体量差异用绝对额。两者不能在同一张图里混画。
- 省份对比图默认占比；省份差额表默认绝对额。

### 12. 把流程差异读成需求差异

- 历史代际可能允许跳过小订（「无小订直锁」占比 0.2% / 0.7% / 5.6%），该口径跨代际不可比。
- 同理：交付兑现率受「是否上市即有现车」影响，不能用来评价订单质量。

### 13. 用当前快照替代历史状态

- 退订、退款、交付必须用事件时间点对点重建到 D_N，不能取当前状态。

### 14. 补零 / 插值

- 缺失日期不补零、不插值；曲线断开并说明，窗口不足给 `window_capped`。

## 三、工程类（导致返工或不可复现）

### 15. 字段缺失导致过滤静默失效

- 症状：测试单过滤前后只差 7 单（2,126 vs 2,119），实际是 `buyer_identity_no` 未加载。
- 修复：`load_orders` 统一声明所需列；过滤后打印前后计数对账。

### 16. 大块替换误删相邻函数

- 症状：`NameError: name 'X' is not defined`，或同名函数定义两份。
- 修复：替换后立即 `ast.parse` + 检查顶层 `def` 列表；发现重复定义立刻删除。

### 17. HTML 里出现裸 `<` 与 Markdown 语法

- 症状：`< 1` 被浏览器当标签吞掉；`**bold**` 与反引号原样显示。
- 修复：用中文表述（「低于」）替代 `<`；统一 `<b>` / `<code>`；交付前 grep 残留。

### 18. 不可复现

- 症状：同参数两次生成的 HTML 不同。
- 根因：Plotly 随机 `div` UUID；`set` 迭代顺序；`value_counts` 平局顺序。
- 修复：固定 `div_id`；所有排序加显式 tie-breaker；重跑做逐字节比对（排除 `generated_at`）。

### 19. 静默 fallback

- `try/except` 吞掉取数失败 → 报告里少了模块却没人发现。
- 修复：失败必须写入 `warnings` 并在报告口径说明中体现。

### 20. 窗口超出数据可用天数

- 对标上市更早但数据未覆盖，会得到错误的「低基数」对比。
- 修复：`build_windows` 取共同可用天数并告警。

## 三之二、v1.1 新增（验收暴露后修复）

### 21. 同档区块按「数据是否存在」判断可比

- 症状：目标代际有 93kWh、但对标没有（如 CM3 vs LS8/LS9）时，`KeyError: 'female'` 直接中断 HTML 生成。
- 根因：用 `dict` 是否为空判断可比，而空段是 `{"n": 0}`（truthy）。
- 规则：**按有效样本量判断**（`n > 0`），不可比时跳过该区块并写明原因，其他章节照常生成。

### 22. 极小总差额不用贡献占比

- 症状：总差额 +42 单时输出「D1 占总差额 2179%」。
- 规则：改用差额结构叙述——「D1 领先 X 单，D2–DN 净回吐 Y 单，最终领先 Z 单」。占比只在 `|总差额|` 足够大（≥ 主车累计 5%）时使用。

### 23. 同名指标跨模块必须能对上

- 症状：同一份报告里「待转化 4,554」与「剩余 10,311」并存，读者无法判断是错还是口径不同。
- 规则：
  - `预售池待转化`（仅预售期小订）与 `封盘池剩余`（含上市当日新增小订）是两个指标，标签必须区分；
  - 报告需给出恒等式校验：`stock_total = pool_total + launch_intent_total`、`remaining = stock − locked − refunded`、`remaining = 预售待转化 + 当日新增未转化`。

### 24. 章节顺序由数据决定

- 症状：无论数据形态如何，都按 Q1→Q10 固定顺序呈现。
- 规则：先产出章节规划（主线判定 + 第二/三幕顺序 + 跳过项），渲染器消费规划；编号沿用固定问题 ID，只调整呈现顺序。
