# 质量与验收

正式报告只输出可复算事实和明确标注的算术分解；假设与机制解释留在独立探索产物。

必须保留的门禁：

1. Gate A 前置核验数据新鲜度、完整日期、主键唯一、时间顺序、代际与窗口及样本量，不允许默认 PASS。
2. Gate B 逐条核对 Findings 的全部数值、比较对象、方向及正文；逐日累计、来源四类和、差额、池事件率与分解恒等式必须通过。
3. 互斥性检查不能被同一公式回算代替。锁退重叠仍须审计；旧池恒等式在缺重叠证据或存在重叠时 FAIL，不得恢复剩余池输出。
4. Gate C 读取 HTML 实际单元格文本，核对指标绑定、全部结论及未提供分析说明；不能仅匹配标题或禁用词。
5. 任一 Gate 失败非零退出且无本次成功交付物。生成产物前后核对输入 SHA256。
6. CM3 与 LS8Neo 原始数据独立复算、所有保留能力、表格实际值、错误注入与两次运行文件比对。允许差异仅生成时间。
7. 不删除失败测试，不以停用业务专题为由撤掉有效质量门禁。已有测试目录没有 launch-deep-dive 专项测试，本轮新增覆盖旧错误和阻断行为。

完整矩阵见 [verified-capabilities.md](verified-capabilities.md)，可执行测试 `workspace/tests/test_launch_deep_dive_stable.py`。
