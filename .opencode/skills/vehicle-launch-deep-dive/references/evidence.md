# 证据分级与核验

## 一、三级证据

| 级别 | 定义 | 报告写法 | 示例 |
|---|---|---|---|
| **事实** | 可由数据直接复算，给出公式与口径即可重现 | 陈述句 + 数值 + 口径 | 「D1–D5 锁单 2,166 单，其中预售小订转锁 1,732 单」 |
| **解释** | 有分解支撑，能说明机制；换口径后方向稳定 | 陈述句 + 分解份额 + 稳健性 | 「预售池规模解释了对 CM3 预售差额的 89%」 |
| **假设** | 方向合理但缺数据；或只有单点证据 | 显式标注 + 验证方式 + 所需数据 | 「湖北强可能源于区域活动投放，需市场费用数据验证」 |

反例（不算任何一级）：
- 「产品力更强/更弱」——没有定义，不可复算。
- 「用户更喜欢」——只有占比，没有对照。
- 「预计下月能到 X 单」——有预测无区间、无判据。

## 二、核验动作（交付前必做）

1. **独立复算**：从 `dataset/order_data.parquet` 与 `config_attribute.parquet` 用新脚本重算 3–5 个关键数字（总量、份额、价格、组合占比）。
2. **恒等式检查**：
   - 来源三分之和 = 窗口锁单总数
   - 各表百分比合计 = 100%
   - 省级分解求和 = 全国差额
3. **稳健性检查**：去掉单一大省/单一渠道后，结论是否反转。反转则必须写明。
4. **反证检查**：主动找一条与结论相反的证据（如「六座更富」但试驾参与率更低），写进报告。
5. **可复现检查**：同参数重跑，HTML（除时间戳）与 CSV/JSON 逐字节一致。

## 三、结论强度的写法

- 差距 > 20% 且样本 > 500：可直接陈述。
- 差距 < 10pp 或样本 < 100：写「方向性」，不下强结论。
- 单省/单店结论：必须附样本量，并说明是否为小样本波动。
- 显著性检验可选（两比例 z 检验），用于「某省份额是否真的变了」这类问题；报告里给 z 值与结论，不堆公式。

## 四、必须写进报告的限制

- 数据截止日与「最后完整观察日」的差异
- 窗口被截断的原因（`window_capped`）
- 口径外样本数量（如小订晚于上市日 24:00 的残余）
- 无法拆分到单车型的数据（series 级）
- 缺失维度（无线索/试驾单车型数据时）
- 业务定义缺口（如版本→电量映射未正式登记）

## 五、交付物清单

| 产物 | 必备内容 |
|---|---|
| HTML 报告 | 核心发现 3–5 条、四幕正文、经营判断、附录口径 |
| 口径说明 MD | 窗口公式、过滤规则、指标定义、已知限制 |
| 数据表 CSV | 与报告数字一一对应，可复算 |
| `metrics.json` | 机器可读的全量指标，供二次分析 |
| `result_contract.json` | scope / result / artifacts / warnings |
