# 口径说明文档骨架

文件名：`{GEN}_数据口径与差异计算说明.md`，与 HTML 报告同目录。

```markdown
# {GEN} 上市第 {N} 天深度研究 — 数据口径与差异计算说明

- 生成时间：YYYY-MM-DD HH:MM:SS
- 数据观察截止：{as_of}（T−1，最后完整观察日）
- 生成脚本：`workspace/research_scripts/launch_deep_dive.py`（计算）
            `workspace/research_scripts/launch_deep_dive_report.py`（呈现）

## 1. 时间规则与窗口

N = (T−1 − T0).days + 1 = {N}
窗口 = [T0, T0+N) 左闭右开，第 d 天 = T0 + (d−1)

| 代际 | 上市日 T0 | 窗口末日 | 星期结构 | 预售开始 | 预售天数 |
|---|---|---|---|---|---|

## 2. 代际映射

来自 `series_group_logic`（product_name 匹配，priority 降序裁决），不按字符串猜。

## 3. 过滤与口径

| 口径 | 规则 |
|---|---|
| 零售锁单 | order_type = 用户车；剔除测试单（总部主理店 + 非 18 位身份证）、总部主理店整店、NON_RETAIL |
| 小订池 | 允许 order_type 为空（未回填），其余同零售 |
| 锁单来源 | 预售 / 上市当日新增 / 直接锁单；晚于上市日 24:00 的残余单列 |

## 4. 指标定义

| 指标 | 定义 |
|---|---|
| 累计锁单 | lock_time 非空 COUNTD(order_number) 在 [T0, T0+N) |
| 边际差额 | Δ(d) − Δ(d−1) |
| 预售池 | intention_payment_time < T0 |
| 锁/退比 | 已锁 / 已退（截至 D_N） |

## 5. 差异计算

Δ_b(d)、预售二元分解、区域绝对差额、网络分解、省级渠道分解（公式）。

## 6. 已知限制

- 窗口截断、口径外样本、series 级数据、缺失维度、业务定义缺口

## 7. 产物

- 报告 / 数据表 / 图表路径
- 复现命令
```

## 写法要求

- 每张表都要能对到具体过滤与时间窗口；不能出现「约」「大概」。
- 已知限制至少 5 条，写清「缺什么数据可以补齐」。
- 复现命令必须可直接复制执行，参数与本次一致。
