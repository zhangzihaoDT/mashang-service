# HTML 报告骨架

> 结构固定、内容按数据长出来。不要求十问平均分配篇幅，按解释力排序。
> 视觉遵循 `docs/共享规范/report_visual_system.md`：主色承担主对象、辅色承担对标、强调色做标记。

## 0. 页头

- 标题：`{GEN} 上市第 {N} 天深度研究——与 {B1}、{B2} 的历史同期比较`
- 副标题：研究窗口（各代际自身上市后 D1–D{N}）、数据截止日、对标上市日、口径一句话
- KPI 卡：主车累计锁单、两个对标的累计与差额、预售池

## 1. 核心发现（3–5 条）

每条包含：结论句 + 关键数字 + 证据类型标签（事实/解释/假设）。
禁止出现没有数字支撑的判断。

## 2. 第一幕　卖得怎么样

- Q1：累计曲线（D1–D_N 实线；D_N 之后虚线仅作参考并注明不参与计算）
- Q2：边际差额表（哪天贡献最大）
- Q3：日增柱状图 + 日增表

## 3. 第二幕　差异为什么出现

- Q4：预售池表 + 二元分解（池规模 / 转化率）
- Q5：来源三分 100% 堆积条 + 三分表 + 口径外残余说明

## 4. 第三幕　差异发生在哪里

- Q6：省份表（绝对差额 + 单元格内条形图）+ 城市表
  - 若做版本缺口验证：省份清单必须与 Q6 对齐
- Q7：门店规模 / 单店产能两张柱状图 + 网络分解表
- Q8：拆成三问
  - 谁在买：客群结构表（性别 / 年龄均值 / 四档线级 / Top3 省份）+ 同档对比
  - 选什么：三车型配置结构（各一张 in-cell 堆积条表）+ 集中度
  - 能解释什么：用户差异矩阵（固定维度顺序）+ 细分对比
- 竞争视角（可选）：上市周 vs 预售周 PK 卡片（竞品次数 + 反向排名变化）

## 5. 第四幕　意味着什么

- Q9：订单质量表（退订/退款/兑现，点对点重建）
- Q10：封盘池 → 流出速度（锁/退比）→ 剩余池区间 + 验证判据
- 经营判断：5 个问题逐条回答（差在哪、能解释什么、反映什么、能否持续、下一步验证什么）

## 6. 附录

- A：数据口径与差异计算说明（窗口、过滤、指标、分解公式）
- B：数据审计（行数、覆盖天数、各代际剔除量）
- C：已知限制与待补齐数据

## 排版约定

| 元素 | 规范 |
|---|---|
| 章节 | 四幕各一个 section，幕内问题用 `<p class="q">` |
| 表格 | 差额列用 in-cell bar；百分比与绝对值不混列 |
| 图表 | 一图一问；顺序固定；`.png` 可导出 |
| 标注 | `事实` / `解释` / `假设` 三种标签，颜色区分 |
| 数字 | 千分位；百分比 1 位小数（<1% 时 2 位） |
