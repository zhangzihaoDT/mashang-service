Search Agent v2.3

证据驱动的 Agent 搜索闭环
v2.3 — 2026-07-30

架构总览

从自然语言搜索请求出发，经过意图编译、证据驱动的迭代搜索、缺口分析、停止决策，最终输出结构化结论和 claim-level 证据评估。

意图编译 → 初始搜索 → 证据评估 → 缺口分析 → 查询改写 ↻
核心分层原则：
Coverage 负责搜索循环控制（搜够没有），Claim 负责结果理解（搜到的东西意味着什么）。两套系统互不污染。

模块说明

意图编译器（search_intent_compiler.py）

将自然语言请求解析为结构化意图：目标车型（brand+model）、监控模式（brand_watch / model_watch / buzz_watch）、时间窗口、事件范围、信源策略。

Agent 搜索循环（orchestrator.py）

多轮迭代搜索：Round 1 使用 profile 初始查询模板，后续轮次由缺口分析驱动。

  • 初始查询已自带 抖音 bilibili 话题 等平台关键词
  • 支持 --batch 批量多车型 + --fresh 禁止混入缓存

证据评估器（evidencer.py）

field-level 覆盖检测 + 停止决策。包含三部分：

  • 字段覆盖：三层加权（identity×0 + metadata×0.6 + evidence×0.8），使用 match_keywords 语义匹配
  • 信源分类：publication_tier_map 将中文媒体名映射为 official / media / social
  • 停止决策：按优先级评估 confirmed → fallback → hard_limit → weak_signal，阈值由 profile 的 stop_thresholds 控制

Claim 评估器（claim_evaluator.py）— v2.3 新增

将 field-level binary coverage 升级为 claim-level multi-quality evidence。两个正交维度：

  • quality：证据本身是什么（mention_only / qualitative / quantitative / official）
  • direction：证据支持还是反对 claim（support / contradict / neutral）

两个聚合维度：

  • value：结论内容（high / low / positive / negative / mixed / present）
  • status：确信度（unknown / partial / probable / confirmed）

缺口分析 + 查询改写（gap_analyzer.py + query_rewriter.py）

基于 missing_fields + source_tier_gaps + unresolved_claims 生成下一轮搜索目标。仅 field-level 参与循环控制，claim-level 不干预搜索。

Profile 体系

三个预置 profile，控制资源边界和停止阈值：

Profile轮次/查询/APIconfirmed 条件fallback 条件
lite_scan 1 / 3 / 5 ≥2源 + ≥1官源 + ≥80% ≥3源 + ≥2类型 + ≥70%
standard_scan 2 / 6 / 8 ≥3源 + ≥1官源 + ≥80% ≥5源 + ≥2类型 + ≥70%
deep_scan 3 / 10 / 15 ≥5源 + ≥2官源 + ≥90% ≥8源 + ≥3类型 + ≥80%

证据质量体系

每个 EvidenceItem 包含两个正交维度：

quality（证据本身是什么）

等级含义判断依据分数
official官方源publication_tier_map 标记为 official+3
quantitative有定量数据包含数字+单位（"999台"、"34.98万"）+2
qualitative有定性描述含程度/情感词（"爆火"、"热议"）+1
mention_only仅提及命中 match_keywords 但无实质细节0

direction（证据对 claim 的支持关系）

方向含义
support支持 claim 默认值
contradict含 field 相关的反证关键词（如 sentiment 的"投诉"、"被骂"）
neutral中性

Claim 聚合

分数制聚合：

总分status说明
≥6confirmed有官方或充足的定量证据
3-5probable有定量数据支撑
1-2partial有定性描述
0unknown证据不足

使用方式

# 单车型 deep_scan
python -m auto_launch.src.search_agent_v2.run \
  --request "看看 MG 07 的微信指数和声量热度最近 7 天" \
  --live --fresh --profile deep_scan

# 批量多车型
python -m auto_launch.src.search_agent_v2.run \
  --batch --targets "MG 07" "智己 LS9" \
  --live --fresh --profile deep_scan

# lite_scan 快速问答
python -m auto_launch.src.search_agent_v2.run \
  --request "MG 07 声量怎么样" \
  --live --profile lite_scan
