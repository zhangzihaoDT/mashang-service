## 五车报告

样本截至 2026-11-22，为大F M0、小F M0、CM3、CM2 纯电和 DM2 的 77,901 张用户车锁单，沿用现有订单筛选及录入模板审计，剔除 1 单。原有筛选包含部分上市前锁单，报告标题据此改为「用户车锁单」。

| 样本内属性覆盖 | 按中文名 | 按属性编码 |
|---|---:|---:|
| 默认可见属性 | 19 | 12 |
| 默认仅一组有记录 | 16 | 8 |
| 含默认排除项的全部原始属性 | 25 | 18 |
| 含默认排除项且仅一组有记录 | 19 | 11 |

任务单的 42 → 24 来自 196,020 单试算样本。本地使用同一份订单表扩至五代际全部动力类型、保留原始属性和全部订单时，覆盖 104,982 单，得到 25 → 18 个属性。因此这次回归以同一默认报告样本的前后对比核验。

- `OP-LASER`、`OP-FRIDGE`、`OP-Steer` 在属性覆盖表各一行。跨车型取值矩阵只包含轮毂尺寸和冰箱是否选装。HTML 注明 LS8 档位和 `OP-Battery` 套包的语义差异。
- 逐车型复算原名称下显式「是」的订单集合并求并集，汇总单数及比例与报告一致。混合编码样例也验证了同订单跨别名去重，以及已知编码相互独立。
- LS8 激光雷达渗透率以 2026-10-24 至 2026-11-22 为窗口，按 `series=LS8` 和原脚本口径，重建前后均为 80.9%（3,043 / 3,760）。任务单基线为 81.0%（3,043 / 3,759），本地订单表的分母多 1 单。
