# 数据资产索引

数据资产按正式业务表、原始与增量输入、市场数据、专题样本、接收区和群聊数据分类。文件位置、更新方式和校验见 [数据集获取与更新操作手册](../docs/数据获取/dataset_operations.md)。更新程序见 [updater 索引](updater/README.md)。

| 路径 | 内容 |
|---|---|
| `tableau/` | 订单、选配、归因和库存的原始或增量 CSV |
| `market/` | 盖世汽车和乘联会数据 |
| `research/` | A3 流转、人群研究和 NEV-APEAL 样本 |
| `TP&MIX-ways/` | 独立上险数据包 |
| `incoming/` | 下载和解析接收区 |
| `wechat/` | 群聊历史数据 |
| 根目录 CSV / Parquet | 共享业务消费入口及门店运营产物 |
