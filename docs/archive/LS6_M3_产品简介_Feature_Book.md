## 2. 三大下一代核心科技

### 2.1 下一代全线控灵蜥底盘（安全与操控）

| 项目 | 参数 / 描述 |
|---|---|
| 底盘形式 | **全系标配全线控底盘** |
| 安全冗余 | 航空级**三重安全冗余**设计 |
| 协同控制 | SynVector 全域线控矢量扭矩协同控制系统 |
| 响应速度 | **20 毫秒**极速响应，可提前辅助制动、避让 |
| 转弯半径 | **4.49 米超小转弯半径**，半圈方向盘即可掉头 |
| 转向比 | 行业唯一**三档可调转向比** |

- 安全理念：从"碰撞后保护"升级为"主动规避危险"，原文提出"买车除五星碰撞外，更要看是否搭载全线控底盘"。
- 驾驶体验：高速变道车身姿态平稳顺滑，"眼到、手到、车就到"；三档转向比兼顾操控乐趣与轻便好开。

### 2.3 下一代全域物理 AI 智能系统（智能与座舱）

定位"出行专属副机长"，分智驾与座舱两条线：

**智驾（IM AD Zeta）**

- 智己与 **Momenta** 深度合作：Momenta 创始灯塔合作伙伴，技术共研、相互持股。
- IM AD Zeta 辅助驾驶依托 **L4 级模型能力赋能 L2** 功能，接入 Momenta **世界模型**，行车表现超越传统辅助驾驶。

**智能座舱（IM CLAW 龙虾智能体）**

- 行业首发 **IM CLAW 龙虾智能体**，打破传统语音助手"仅能问答"局限。
- 定位可**主动完成一连串任务**的 AI Agent，一句话批量处理用车事务。
- 后续将**打通阿里 AI 生态**，语音指令延伸至车内控制之外的生活服务能力。
