# 懂车帝销量数据抓取经验总结

## 背景

需要从懂车帝销量页面（https://www.dongchedi.com/sales）获取智己品牌各子车型（LS6、LS7、LS8、LS9、L6、L7）的 2026 年 6 月零售量数据并汇总总量。

## 问题与解决

### 问题一：页面需登录验证

懂车帝销量页面 `/sales` 需要用户登录才能访问，否则重定向到验证码中间页（`/login-required`），所有子路径（`/sales/brand`、`/sales/series` 等）同样受限。

**解决**：让用户在浏览器中手动登录懂车帝，之后 Playwright 可以复用其登录态正常加载页面。

### 问题二：榜单只显示 Top 10

登录后销量榜默认只渲染前十名车系，智己车型销量较低（排名 100+），不在首屏范围内。

**解决**：页面是服务端渲染 + 客户端 Hydration 架构，所有车系的完整列表数据实际已嵌入 DOM。使用 `document.querySelectorAll` 或 `evaluate` 直接读取 DOM 中的全量列表，而非依赖屏幕可见区域。

### 问题三：Playwright selector 限制

`playwright_browser_snapshot` 只捕获了 Top 10 列表项的可见 DOM，且 ref 选择器不可用。

**解决**：使用 `page.evaluate()` 执行 JavaScript，直接查询 `li` 元素中文本包含"智己"的条目，从中提取销量数字。关键 API：

```javascript
document.querySelectorAll('li')
// 配合 textContent.includes('智己') 过滤
```

## 关键发现

- 懂车帝销量数据已嵌入页面 DOM，不需要等待滚动或翻页即可获取全量
- 页面 DOM 中每个车系的 `<li>` 元素包含：排名、车系名、品牌、价格区间、销量数字等完整信息
- 每月 10 号左右更新上月数据（页面标注：数据源于行业综合销量）

## 数据格式

从 DOM 中提取的原始文本示例：

```
1381智己LS6智己汽车/中大型suv18.99-26.69万...3,661...销量趋势...询底价...二手车
```

解析方式：按车系名分割，销量数字在车系名之后的固定位置出现（作为独立文本节点）。

## 适用场景

此方法适用于：
1. 批量抓取懂车帝月度销量排行榜任意品牌/车系的数据
2. 需登录但数据已预渲染到 DOM 的 SPA 页面
3. 车系排名较低、不在首屏但 DOM 中存在的场景

不适用于：
1. 需要查看销量趋势图（需点击按钮加载动态数据）
2. 需要跨月份对比的明细（需切换月份参数重新加载）

## 经验教训

- 不要被首屏渲染范围限制：先检查 DOM 是否包含全量数据
- Playwright 的 `evaluate` 是最通用的数据提取方式，不受 snapshot layer 限制
- 登录态是懂车帝数据抓取的唯一门槛，登录后无需额外 API 调用
