# MIIT 附件字段来源汇总

> 基于第 409 批数据，`reports/batch_409/category_report/` HTML 报告的字段来源说明

## 数据源

- **附件1 企业申报详情页**：品牌归档 .md 文件（`MIIT/data/vehicle_details/车型型号-产品名.md`），对应 "道路机动车辆生产企业及产品公告" 中的单车申报详情页
- **附件2 车船税目录**：车船税 JSON（`MIIT/data/vehicle_tax/车型清单_第88批车船税.json`），对应 "享受车船税减免优惠的节约能源 使用新能源汽车车型目录"

## 字段级映射

### 整车尺寸 — 全部来自 附件1 详情页

| 报告显示字段 | md_data key |
|-------------|-------------|
| 长(mm) | `外形尺寸(mm)` 中的 "长" |
| 宽(mm) | `外形尺寸(mm)` 中的 "宽" |
| 高(mm) | `外形尺寸(mm)` 中的 "高" |
| 轴距(mm) | `轴距(mm)` |

### 动力与底盘 — 全部来自 附件1 详情页

| 报告显示字段 | md_data key |
|-------------|-------------|
| 申报动力形式 | `新能源类型` / `燃料种类` / `产品名称`（优先级依次） |
| 增程器（发动机型号/排量/功率/企业） | `发动机型号` + `排量_ml` + `发动机最大净功率_kW` + `发动机企业` |
| 驱动电机(kW) | `驱动电机峰值功率_kW` / `功率_kw` |
| 座位数 | `额定载客_人` / 含"座位"的字段 |
| 整备质量(kg) | 优先车船税 `整车整备质量_kg`，备选 `整备质量(kg)` |

### 电池与续航 — 混合来源

| 报告显示字段 | 来源 | 具体 key |
|-------------|------|----------|
| 电池类型 | 附件1 详情页 | `储能装置种类`（或从 `其它` 备注中 regex 提取） |
| 电芯及电池总成 | 附件1 详情页 | `电池单体_总成企业`（或从 `其它` 备注中 regex 提取） |
| 电池容量(kWh) | **附件2 车船税** | `动力蓄电池总能量_kWh` / `动力蓄电池组总能量_kWh` |
| 纯电续航(WLTC)(km) | **附件2 车船税** | `纯电动续驶里程_km` |
| 电池质量(kg) | **附件2 车船税** | `动力蓄电池总质量_kg` / `动力蓄电池组总质量_kg`（JSON 中含，当前报告未展示） |

## 合并逻辑说明（`scripts/report_common.py:extract_all_params`）

1. **尺寸/动力/电池类型/供应商/座位数**：直接使用附件1详情页的字段
2. **电池容量 + 纯电续航 + 整备质量(优先)**：使用附件2车船税 JSON 的字段
3. **整备质量(备选)**：如车船税中无此车型，则降级使用附件1详情页的 `整备质量(kg)`
4. **电池质量**：车船税 JSON 中含有 `动力蓄电池总质量_kg`，但当前 HTML 报告模板未渲染此字段
