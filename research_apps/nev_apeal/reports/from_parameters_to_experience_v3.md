# P1｜Topic Opening

> 一句话 thesis：
> **从参数升级到体验升级：已有车辆经验的用户，正在重新定义新能源车的"升级感"**

```

```

# P2｜Who

> 一句话：
> **增购用户不是"碰巧更满意"：控制主要产品结构后，优势依然存在**

**核心视觉：三根柱 / 三点（coefficient path）**

```
增购优势（vs 换购）
raw             ≈ +14.8
+能源/价格/品牌   +18.3   (p<0.001)
+SEGMENT_DP      +18.17  (p<5e-07)
```

**结论：这是稳定的人群差异，不是结构 mix。**

- 演讲备注：三根柱子几乎一样高 = "结构控制动摇不了它"。参照组陷阱已排除（+11.8→+18.3 是对照差异，非 suppression）。
- 口径注：SEGMENT_DP 是数据集中车型结构的最佳代理——17 类"车身尺寸/级别 × BEV/PHEV 技术路线"细分市场段（**不是** A/B/C/D 尺寸级别）；数据无车型级列，故用它代车型。

# P4｜Mechanism

> 一句话：
> **驾驶差异不是抽象指数，而是落实到整体驾驶质感与转向手感**

**核心视觉：ADRV item 下钻（打穿到 Question/Item）**

| 突出（高亮） | Δ | d |
|---|---:|---:|
| **总体驾驶感受** | **-0.23** | **-0.215** |
| 常规路况转向/操控 | -0.17 | -0.123 |
| 湿滑路况转向/操控 | -0.18 | -0.094 |
| ~~制动性能~~（弱化置灰） | -0.13 | -0.112 |

- 不要把 5 个 item 全塞表格：突出前三项，制动弱化。
- 演讲备注：这一页证明研究真的打穿到了 Question/Item 层，而不是停在指数。

# P5｜How 　⭐ 第二张 Hero Slide

> 一句话：
> **高感知配置与体验稳定关联，但配置数量本身并不能制造魅力**

**核心视觉：左证据 / 右反证**

```
左（配置 × 体验，匹配关联）  右（反证）
记忆座椅 关联 驾驶体验 +19.3  换购：记忆座椅拥有率 49%（三组最高）
主驾通风 关联 驾驶体验 +13.3  换购：APEAL 却最低（783.6）
```

**标题（二选一）：**
> *Feature ownership is not perceived value.*
> 配置是载体，体验才是价值。

> 口径注：左侧为品牌×价格带匹配后的 **observational 关联**（非因果），与 v2 的"横截面关联非因果"边界一致。

- 这是全篇第二张 Hero Slide——因为它是"反直觉 + 反证"最锋利的一页。

---

# P6｜Boundary

> 一句话：
> **价格越高，并不会线性放大增购优势——高端市场已经进入"全民体验竞争"**

**核心视觉：价格带 × purchase mission（增购 vs 首购）**

```
10-15万  增购−首购  +3.1
15-20万  增购−首购  +20.4   ← 中端：靠升级感拉开用户（唯一峰值）
20-30万  增购−首购  +3.3
30万+    增购−首购  +1.4    ← 高端：首购也拉满，任务趋同
```

**研究成熟度的体现：** 我们没有把一个漂亮的"越贵越明显"故事硬讲下去。四档看下来**非单调**：15-20万 是唯一的尖峰，20-30万 已回落，30万+ 完全收窄。

**衍生一句：**
> 中端靠升级感拉开用户，高端靠体验基准留在牌桌。

---

# P7｜OEM Implication

> 一句话：
> **从 Feature Checklist 转向 Perceived Upgrade Design**

**最终三句话就够：**

1. **参数是门槛，不是升级感本身。**
2. **高感知配置必须转化为可感知体验，才产生产品魅力。**
3. **产品验收应从"多了什么"转向"用户能否立即感觉不一样"。**

**用产品定义问题收尾：**

> 用户第一次开、坐、转向、使用这些配置时，
> 能不能立即感知这辆车升级了？

- 演讲备注：这个结尾比普通"建议加强驾驶体验"强很多——它把结论落回了一个可执行的产品定义问题。
