# OEM 来源结构差距——验证结果

**日期**：2026-08-19
**数据源**：`data/source.sav`（9,937 行，权重 APEAL_WT）
**Run**：`research/runs/oem_traditional_gap/`（E-001~E-012）
**结论**：**READY（终态）** —— 传统国产 OEM 相对国际 +14.3 / 新势力 +13.7 的 APEAL 差距**不存在品牌级不可归因残余**，完整控制（结构 + 人口学 + 品牌形象 + 使用强度/场景）后归零。

---

## 结论一句话

**传统国产 vs 国际/新势力的体验差距完全由「产品组合（高端细分）+ 人口结构 + 品牌形象 + 使用方式」综合解释，无独立 OEM 机制。控制结构后残余约 +6~9 分，加入品牌形象即失效（WLS +2.7，p=0.53），OEM 不构成独立分割变量。**

---

## 验证设计

- **segmentation 变量**：`ORIGIN3_DP`（1=Domestic Traditional 基准 / 2=International / 3=Domestic Startup / 4=Domestic Affiliated）。
- **队列**：H1 Robustness → H2 Segmentation → H3 Mechanism → H4 Discriminator → H5 Alternative explanation。
- **关键口径修正**：E-001 起弃用共线 `MAKE_DP`，改用 `PREMMAKE_DP`（豪华/大众）+ `SEGMENT_DP`（车身细分）。

## 五层证据

### 1. H1 Robustness（E-001/E-005/E-006/E-008）— 残余逐步瓦解

| 控制状态 | 国际 | 新势力 | 附属 |
|---|---:|---:|---:|
| raw | +14.28 | +13.73 | +3.49 |
| + 能源/价格/豪华/车身 | +8.87 (p=0.030) | +6.52 (p=0.047) | -1.53 |
| + 年龄 | +8.87 (p=0.030) | +6.47 (p=0.048) | -1.65 |
| + 收入 | +6.85 (p=0.092) | +5.84 (p=0.073) | -2.07 |
| + 教育 | +6.23 (p=0.126) | +5.79 (p=0.075) | -2.35 |

**收入/教育吸收过半且 p 跨 0.05**——「不可归因品牌级残余」的声明不成立，降级为有限残余（边缘显著）。

### 2. H2 Segmentation（E-007/E-009）— 溢价是产品组合非品牌溢价

- SEGMENT×ORIGIN 交互**不可识别**：Premium BEV(n=340)/Premium PHEV(n=133) 几乎全为国际，多数大众细分几乎全为传统国产——高端无对照。
- 可测范围内（两来源共存 3 细分，n=1040/497/841）受控 gap **全部不显著**：Compact BEV Car -3.30、Midsize BEV Car -2.88、Midsize BEV SUV +9.02。
- 价格带交互联合 F=1.71，p=0.057 边缘。
- 国际高分 ≈ 集中在无传统国产对照的高端细分（产品组合），而非同一细分内的品牌溢价。

### 3. H3 Mechanism（E-002/003/004/E-010）— 感知质量而非纯 halo

受控模块 gap 分层（n=9450，结构控制）：

| 模块 | gap | p |
|---|---:|---:|
| 外观 AEXT | **+11.87** | 0.009 |
| 驾驶 ADRV | +10.93 | 0.010 |
| 安全 ASFTY | +9.93 | 0.021 |
| 内装 AINT | +9.61 | 0.032 |
| 进出 AENT | +9.32 | 0.036 |
| 性能 APERF / 补能 ACHAR | +8.33 / +6.90 | 0.060 / 0.088 |
| 舒适/设置/续航/智能座舱 | ≤+6.6 | >0.17 |

item 层：`ADRV_R_03`（转向/NVH）**+0.305（p<0.001）独大**，R_04 +0.155、R_02 +0.140 显著；APERF 全部 item p>0.36 全灭（原始 +0.16~0.22 被吸收）。机制 = **感知质量（外观 + 驾驶调校）**，非纯 halo 亦非纯工程短板。

### 4. H4 Discriminator（E-006/E-011）— 国际/新势力同质

统一样本结构+人口学控制后：国际 +7.70 (p=0.073) / 新势力 +6.75 (p=0.048)，WLS 后 +7.89/+6.33 均边缘。**新势力未被吸收**（与 E-006 控形象结论相左，差异来自控制变量选择）——两类来源残余同质，差异是功效而非性质。

### 5. H5 Alternative explanation（E-012）— **残余完全归零（决定性）**

统一样本（n=5900）：

| Block | 国际 | 新势力 |
|---|---:|---:|
| full（结构+人口学） | +9.17 (p=0.052) | +8.72 (p=0.021) |
| + 品牌形象 YNV_CN_6 | +5.07 (p=0.223) | +3.57 (p=0.282) |
| + 使用强度 NEV_12/13a | +4.89 (p=0.238) | +3.36 (p=0.312) |
| + 使用场景 NEV_11A-G | +4.37 (p=0.288) | +2.60 (p=0.429) |
| **WLS 终模** | **+2.74 (p=0.530)** | **+0.21 (p=0.956)** |

**品牌形象是主要吸收项**——加入后国际/新势力双双失效到近零。OEM 维度无超出「结构+人口学+形象+使用强度/场景」集合的独立解释力。

## 机制解读

- **无品牌级残余**：`ORIGIN3_DP` 相对传统国产的差距全部可被既有观测变量解释。
- **gap 构成**：产品组合（国际集中于无对照高端细分）+ 人口结构（收入/教育）+ 品牌形象（感知变量，观察性下亦可能是中介/驱动）+ 使用方式。
- **感知质量线索**：即使结构性差距存在，其内容指向外观与驾驶调校（ADRV_R_03 转向/NVH 独大），非纯光环。

---

## 对业务的意义

1. **OEM 来源不是独立变量**：传统国产的差距不是「品牌光环诅咒」，而是产品组合、人群结构与形象的综合结果——**通过产品上探高端细分与补齐驾驶调校可弥合**。
2. **驾驶调校（转向/NVH, ADRV_R_03）是残余最大可操作项**：外观 +11.9 与驾驶 +10.9 并列为结构控制后的最大承载。
3. **品牌形象是关键传导层**：形象既是差距来源也是忠实的观察性中介——对 OEM 同等重要的形象管理与产品力一样是体验差距的一环。

---

## 边界

- 观察性横截面，品牌形象为感知变量，残余归零也可读作「形象中介/驱动」而非纯混淆——因果方向不可判定。
- H5 统一样本 n=5900（形象/使用强度 union dropna，较 n=9450 损失约 38%）。
- `ABRAND_Index`（品牌模块）未纳入模块分解主表；形象仅用 YNV_CN_6 7 题。
- 结论不覆盖跨年趋势或市场份额主张。
