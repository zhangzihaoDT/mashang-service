# 充电生活方式是独立强韧的体验分群——验证结果

**日期**：2026-08-19
**数据源**：`data/source.sav`（9,937 行，权重 APEAL_WT）
**Run**：`research/runs/charging_lifestyle/`（E-001~E-006）
**结论**：**READY** —— 快充依赖度（NEV_08）作为 segmentation 变量，定义一个独立、强韧的"充电生活方式"体验分群。不是补能因果机制，也不是使用强度的纯 proxy。

---

## 结论一句话

**从不依赖公共快充的用户（家充 + 轻出行）整车拥有体验全面领先（完整控制后 +27~46 分），能源 / 价格 / 品牌 / 人口学 / 使用强度 / 使用场景 / 家充 / 慢充全部无法解释；差异全方位（非补能特异），其中充电体验（快/慢充速度 item）是最大的单一承载模块。**

---

## 验证设计

- **segmentation 变量**：`NEV_08`（快充频率，有序 6 档 = Everyday → Never used fast charging），**不预设因果**，机制未知开放探索。
- **队列**：H1 Robustness → H2 Dose-response → H3 补能分解 → H4 跨模块判别 → H5 替代解释。
- **控制集**：SUPER_SEGMENT_DP（能源）+ CN_YNV_07（价格）+ PREMMAKE_DP（豪华/大众）+ AGE_BUCKETS / CN_INCOME / CN_EDUCATION（人口学）。

## 五层证据

### 1. H1 Robustness（E-001 / E-002）— 效应抗混淆

| 控制步骤 | Never 系数 | p |
|---|---:|---:|
| exposure only | +52.37 | <0.001 |
| +能源 / 价格 / 品牌 | +52.36 | <0.001 |
| +年龄 | +52.33 | <0.001 |
| +收入 | +48.10 | <0.001 |
| +教育 | **+47.89** | <0.001 |

系数路径全步 p<0.001，仅收入吸收 ~4 分，方向与显著性不变。

### 2. H2 Dose-response（E-003）— 三梯度台阶而非严格单调

- 总趋势单调：ordinal slope **+9.08/dose**（p<0.001）。
- 但显著偏离线性（nested F=11.97, p<0.001），真实结构为**台阶**：

| 梯度 | 组成 | 加权 APEAL |
|---|---|---:|
| 快充依赖 | Everyday / 每周≥2次 | ~769-771 |
| 偶尔快充 | 每周1次 ~ 每月≤1次 | ~789-796 |
| 从不快充 | Never | **814** |

- dose4→dose5 反转 -7.74（p=0.025）显著非噪声；最大台阶在"从不"（+24.9）。

### 3. H3 补能分解（E-004）— 补能是最强但不是唯一

- ACHAR（充电体验）控制后 **+66.4**（p<0.001），超过 APEAL 总 gap（+47.9）；AFUEL +38.6。
- item 定位（Never−Daily，10分制）：**快充速度 +0.98 / 慢充速度 +0.98**（并列最大）→ 整体充电体验 +0.77 → 缆长 +0.48；**续航（AFUEL_R_01）+0.38 全部项最小** —— 不是续航焦虑，是充电体验本身。

### 4. H4 跨模块判别（E-005）— H-004 **拒绝**：差异全面

| 模块 | 控制后 gap | p |
|---|---:|---:|
| 设置启动 | **+67.5** | <0.001 |
| 补能·充电 | +66.4 | <0.001 |
| 进出便利 | +61.5 | <0.001 |
| 安全 / 智能座舱 / 座舱内装 / 性能 | +55.9~+59.0 | <0.001 |
| 总体 | +47.9 | <0.001 |
| 舒适 / 驾驶感受 / 补能·续航 | +38.6~+44.0 | <0.001 |
| 外观 | +19.1 | 0.021 |

11/12 模块全部显著、量级相近 —— **差异是全方位的**，充电模块只是其中最大的一个。NEV08 更可能是生活方式 / 使用强度的分群变量，而非补能机制。

### 5. H5 替代解释（E-006）— 残差仍显著，独立分群成立

统一样本（n=4509）逐块加控制，dose6（从不）系数：

| Block | coef | p |
|---|---:|---:|
| base（FULL） | +45.76 | <0.001 |
| + 使用强度 NEV_12/NEV_13a | +49.32 | <0.001 |
| + 使用场景 NEV_11A-G | **+57.28** | <0.001 |
| + 家充 NEV_05_R1/NEV_07 | +56.46 | <0.001 |
| + 慢充 NEV_01 | +46.37 | <0.001 |
| **加权敏感（WLS）** | **+26.75** | 0.003 |

效应**不消失**，加入使用强度/场景后反而放大（suppression 结构：快充依赖者里程更高，剔除后残差更清晰）。

**分群画像**（加权）：从不快充组 = **家充率 67% + 里程 3912km（最低）+ 价格 18.2万（最低）**；快充依赖组 = 44% + 5129km + 20.8万。低价 + 家充 + 轻出行的用户最满意。

## 机制解读

- **不是补能因果**：H4 已证明差异全方位，不能写"充电体验导致体验差"。
- **不是纯 proxy**：H5 已证明剔除里程/场景/家充/慢充后残差仍显著（WLS +26.8，p=0.003）。
- **真实结构**：快充依赖是"补能条件不足 + 使用强度高"人群的镜像；补能生活方式本身定义了一个独立、稳定、全面的体验分群（观察性）。

---

## 对业务的意义

1. **补能生态（家充方案、快充速度）直接对应体验最薄弱的人群** —— 高快充依赖 = 低体验，充电速度与整体充电体验是补能模块内最大的 item 杠杆（+0.98）。
2. **"从不快充"画像（低价 / 家充 / 轻出行）是最满意的用户群** —— 说明补能便利性对体验满意度的权重高于价格。
3. **分群而非功能叙事**：产品与管理层沟通时，充电生活方式是比"补能体验指标"更强的用户分层语言。

---

## 边界

- 横截面观测关联，非因果；生活方式机制为推断。
- WLS 加权敏感量级减半（+46→+27），但方向与显著性不变。
- H5 统一样本 n=4509（NEV_13a / NEV_05 缺失 union dropna）。
- 非跨年 / 市场份额主张；`NEV_01`（慢充）等补能行为变量未单独做 UNC 式的 cells 验证。
