# 预算优先用户画像｜run_004_budget_persona

> 研究月份：2026-09 · 数据窗口：2026-09-11 – 2026-09-13 · 样本：23 条『产品专家支持每日反馈』记录
> 视角：**从用户起点（预算）出发**，逐条反推产品专家当天可能接触到的用户，再按预算分箱。
> 分箱：`≤20 万` / `20–25 万` / `>25 万`；**预算未知不归纳**。

## 01 方法

1. 逐条读取 23 条记录（前段选择题 + 后段自由文本 + 「其他-补充」），不预设用户类型。
2. 只抽取**用户预算证据**，不把产品售价、竞品售价或专家主观判断当成用户预算。
3. 证据分级：
   - `user_budget_cap`：用户自述预算受限 / 明确超预算；
   - `target_segment_price`：记录把用户明确描述为某价位段人群；
   - `product_price_anchor`：仅出现产品价格锚点，作旁证、不单独分箱；
   - `none`：仅「价格敏感 / 等价格 / 等权益」，无金额 → 未知。
4. 未知记录不进入画像归纳，只作为价格决策机制的背景保留。

## 03 可归纳的预算段画像

### 20 万以下（DS-14）

- **证据**：「1位用户因预算限制选择其他品牌，用户想要搭载宁德时代电池的车型，但相关车型超出预算，最终宁愿选择海狮 08。」
- **可读到的用户**：预算存在硬上限；认可智己的核心配置（宁德时代电池），但目标车型总价超出上限，于是向更低价位的竞品迁移。
- **结论**：价格天花板决定成交归属，而不是产品力；属于**预算受限 → 配置取舍 → 竞品流失**路径。
- **置信度**：low。金额未记录，仅能从「所选车型低于 LS6、LS6『20 万起』」推断为 ≤20 万，外部价格锚点待确认。

### 20–25 万（DS-16）

- **证据**：「目标客户群体少，20万左右轿跑用户在贵阳不多」。
- **可读到的用户**：该车目标人群是**约 20 万级轿跑用户**；但记录同时指出这类人群在二线城市偏少，且到店者留资试驾意愿较高。
- **结论**：目标价位段明确，但线索供给偏薄；属于**价格段存在、规模受限**的判断。
- **置信度**：medium。属专家对目标人群的价位描述，非个体自述；「20 万左右」处在 20 万边界，可能略低。

> 旁证（DS-13，不单独分箱）：「LS6最令人满意的就是20万起就能大满配的策略」——20 万级产品价格锚点被用户接受，佐证 20–25 万是当前需求侧的主要落点，但这是产品售价，不能当作某位用户的预算。

## 04 未知的 21 条：只有价格敏感，没有金额

- LS6 的「价格/权益/优惠」被 **23/23** 条记录列为客户关注主题；但**仅有 1 条**自由文本出现「预算」二字。
- 「未知」记录中的真实信号是**决策机制**，不是预算段：
  - 等待上市价 / 预售权益：「在等上市发布会具体权益」「预售权益感觉诱惑力不大」；
  - 价格观望 / 价格不稳：「用户对价格持观望态度」「价格越稳定越好」；
  - 预算并非唯一约束：DS-11「顾客宁愿选择价格更高配置略低但知名度更高的竞品」——部分用户品牌优先于价格。
- 这些只能说明**价格与权益是普遍下单阻碍**，无法支撑「20 万以下/20–25 万/25 万以上」的归属。

## 05 关键发现

1. **当前数据不支持预算优先画像。** 23 条中仅 2 条可落入预算箱，且均为弱/中证据，无法形成价格段分布。
2. **根本原因是问卷口径。** 日报采集的是门店/客流/主题/竞品/下单阻碍，**没有用户购车预算字段**；因此「价格敏感」到处都是，「预算多少」几乎没有。
3. **可迁移的机制仍然清楚。** 价格敏感以两种方式出现：一是**预算硬约束导致向低价竞品迁移**（DS-14），二是**等待价格与权益导致的观望**（多数记录）。二者是不同问题，前者损失成交，后者延后成交。
4. **预算段与车型的初步对应**（证据薄弱，仅供假设）：约 20 万级对应 L6 目标轿跑人群；LS6 用户群更宽，被描述为家庭用户但预算未知。

## 06 下一轮需要补的数据

只有先采到用户预算，预算优先法才能跑通。建议在每日反馈中新增：

| 字段 | 选项 / 形式 |
| --- | --- |
| 用户购车预算 | 单选：≤20 万 / 20–25 万 / 25 万以上 / 未透露 |
| 可接受最高预算 | 数字（万元） |
| 是否置换 | 是 / 否 |
| 购车阶段 | 了解 / 对比 / 试驾 / 等上市价 / 准备下订 |
| 若流失，转向车型 | 文本 |
| 预算是否为主要阻碍 | 是 / 否 |

采到后，用同一套分箱重跑，即可得到真实的预算段画像与转化差异。

## 07 边界

- 样本为定性、自报、非随机的门店日报，单位是「专家 × 日」，**不是用户个体**；不可据此估计总体比例。
- DS-14 的金额为推断，需外部报价锚点确认；DS-16 为目标段描述而非个体预算。
- 未记录的字段一律为「未知」，不推断、不补造。
