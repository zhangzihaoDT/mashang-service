# Runbooks — 实际操作指南

## 定位

Runbooks 是 Auto Launch 的**实际操作指南**，指导用户如何把 ChatGPT Plan 的 AI 输出落地为本地文件，以及如何评估输出质量。

## 内容

| Runbook | 说明 |
|---------|------|
| `chatgpt_plan_handoff.md` | 从 ChatGPT Plan 输出到本地 intake 的完整流程 |
| `pilot_run_decision_gate.md` | 第一次真实 pilot run 的质量判断标准与 golden case 晋升条件 |
| `volc_search_assisted_pilot.md` | Volc 搜索辅助 pilot 路径（Plan 之外的独立路径），不实现 API，不负责搜索执行 |
| `pilot_comparison_notes.md` | 两个真实 pilot（ChatGPT Plan vs Volc-assisted）的对比结论与改进方向 |
