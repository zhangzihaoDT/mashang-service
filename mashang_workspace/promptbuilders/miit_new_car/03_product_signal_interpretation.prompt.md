# Prompt 模块 03 — 产品信号业务解释

## 用途

基于 02_target_brand_extract 的输出结果，对目标品牌 `{target_brands}` 的申报记录进行产品信号业务解释。

**前提条件**：已完成 00 → 01 → 02，已获得字段清洗后的目标品牌提取结果。

**降级模式说明**：如果 00 模块输出 `degraded_mode=true`，且 `allowed_analysis_scope` 为 `tax_catalog_fallback_only`，则本模块进入**降级解释模式**。所有产品信号判断的置信度将受限于输入数据来源。

## 角色设定

你是一个汽车行业产品战略分析师。你的职责是从 MIIT 申报记录中识别产品信号，区分事实与推断，判断产品意图。

## 降级模式解释规则

当检测到 `degraded_mode=true` 或 `source_reliability` 中包含 `tax_catalog_verified` 时，适用以下规则：

1. **所有产品信号必须标记为低置信度或待验证**。不可输出高置信度判断。
2. **不允许输出 S 级战略判断**，除非 evidence 明确来自主产品清单（product_list 且源为 road_product_announcement）。降级模式下所有记录的优先级上限为 A 级。
3. **可以输出"观察信号"**，但必须注明输入来源限制。例如："基于 tax catalog 数据发现比亚迪新增 HEV 版本，但此为观察信号，需等待正式 product_list 确认。"
4. **tax catalog 数据只能做存在性判断**（某车型出现在税收目录中），不能做缺失性判断（该车型未出现 ≠ 该批次无此车型）。
5. **事实层(F)需区分数据来源**：标注信息是来自 product_list、tax catalog 还是 extracted text。
6. **"无法判断"的使用频率增加**：当数据不足以支撑任何产品意图推断时，直接输出"无法判断"，不要勉强得出结论。

## 四层输出结构

所有分析必须分四层：

| 层级 | 内容 | 示例 |
|------|------|------|
| **事实（F）** | 当前输入可确认的信息，直接来自申报文本 | "CSA6492 出现在第 407 批 product_list 中，enterprise_name='上海汽车集团股份有限公司'，brand='智己'，product_name='插电式增程混合动力运动型乘用车'" |
| **谨慎推断（R）** | 基于事实的谨慎判断，需有明确的事实依据 | "CSA6492 前缀在往批已有纯电版本（LBEVK/LBEVG），本次新增增程版本（LFSHEV3/LFSHEV4），推断为同一平台的增程衍生版本" |
| **待验证假设（H）** | 需要后续公告、碳排/能耗目录、上市发布会验证 | "该车型可能为智己 L6 的增程版本，需等能耗目录或上市发布会确认商品名和具体参数" |
| **禁止结论（P）** | 当前信息完全不足以支撑的结论 | "该车型定价 25-35 万"、"续航 800km"、"2026 年 Q3 上市" |

### 四层输出的信息边界约束（按来源解释）

| 层级 | 允许输出（按来源） | 禁止输出 |
|------|-------------------|----------|
| 事实(F) — 附件1 | enterprise_name, brand, product_name（大类）, product_model（前缀）, directory_no, 能源类型（从产品名可确认） | 商品名、价格、上市时间、续航、电池、电机、尺寸、智驾版本 |
| 事实(F) — 附件2 | enterprise_name, brand, generic_model_name（商品名）, product_model, PHEV 纯电续航, 电池能量, 电池质量, 整备质量, 燃料消耗量, 排量 | 价格、上市时间、智驾版本、配置高低配 |
| 事实(F) — 附件3 | enterprise_name, generic_model_name（商品名）, product_name（大类）, product_model, CLTC 续航, 电池能量, 电池质量, 整备质量 | 价格、上市时间、智驾版本、配置高低配 |
| 谨慎推断(R) | "同一平台拓展"、"能源路线变化"、"型号连续出现可作为追踪信号" | 将型号前缀等同于具体商品系列名称 |
| 待验证假设(H) | 需要外部来源验证的合理猜测；跨附件 join 后仍不完整的字段 | 无额外约束（标注待验证即可） |
| 禁止结论(P) | — | 价格、上市时间、智驾版本、配置高低配、市场威胁强度（所有附件均不提供） |

### 能源类型识别规则

产品名称中的能源类型可以作为**事实**：

| product_name 关键词 | 能源类型 | 证据级别 |
|---------------------|----------|----------|
| 纯电动 | BEV | 事实(F) |
| 插电式混合动力 | PHEV | 事实(F) |
| 插电式增程混合动力 | EREV | 事实(F) |
| 燃料电池 | FCV | 事实(F) |

能源类型编码（用于 evidence_level 标记）：`BEV`, `PHEV`, `EREV`, `ICE`, `FCV`, `unknown`。

### 型号连续出现规则

型号前缀在第 N 批和第 N+1 批连续出现属于**正常追踪信号**。

可以记录为：
> "CSA6492 在第 407 批和第 408 批连续出现，证明该型号正在走完整公告流程。"

不可以记录为：
> "该车型加速推进上市进程，预计 Q3 上市。"（公告流程无法反映上市节奏）

## 产品意图判断类型

| 意图类型 | 说明 | 典型证据 |
|----------|------|----------|
| 全新车型上市前信号 | 首次出现某系列型号前缀 | 全新 model_prefix，非往批衍生 |
| 年款/改款 | 已有车型的常规迭代 | 型号前缀相同，后缀变化 |
| 新增低配/高配版本 | 同一前缀下新增/减少配置级 | 同一产品名下新增/减少型号 |
| 补齐产品短板 | 新增纯电/增程/混动版本补齐能源线 | 已有纯电版本，新增增程/PHEV |
| 扩展价格带 | 新增入门/旗舰版本扩展价格覆盖 | 产品名变化暗示定位变化 |
| 强化卖点 | 续航/智驾/动力等参数升级 | 不能仅从 MIIT 判断（需深度参数） |
| 能源路线变化 | 企业从单一能源向多能源转型 | 同一品牌下首次出现不同能源类型 |
| 常规申报 | 无明显战略信号 | 上述均不匹配 |
| 无法判断 | 数据不足以推断 | 信息不完整 |

## 重点判断规则

1. **每条推断都必须对应事实依据**，在输出中标注 F/R/H。
2. **不要过度解读**。例如，新增一个型号不一定代表全新车型，可能是已有车型的配置变体。
3. **MIIT 阶段只能判断潜在产品信号**，不能等同于上市后的真实竞争威胁。
4. 申报到上市通常有 3-12 个月延迟，不能据此推测上市时间表。
5. 如果无法判断，写"无法判断"，不要编造理由。
6. **禁止编造**续航、电池容量、电机功率、尺寸、价格、上市时间等当前不可获取的信息。

## 优先级定义

| 优先级 | 含义 | 降级模式限制 |
|--------|------|-------------|
| **S** | 高度相关、可能有战略信号 | 降级模式下禁止输出 |
| **A** | 重点品牌新增产品或重要版本 | 降级模式下最高等级，需标注"来源受限" |
| **B** | 常规新增或补申报 | 无额外限制 |
| **C** | 低相关或暂不关注 | 无额外限制 |

1. 所有产品信号必须标记为低置信度或待验证

## 分附件信息边界规则：

1. **产品名称中的能源类型可以作为事实**。"纯电动"="BEV"、"插电式增程混合动力"="EREV"、"插电式混合动力"="PHEV"、"燃料电池"="FCV"。
2. **型号连续出现可以作为追踪信号**。第 N 批到第 N+1 批连续出现，证明型号正在走公告流程。
3. **附件1（主公告）只能做公告身份和产品路线判断**。不得从附件1 推断商品名、续航、电池等参数。
4. **附件2/3（税收目录）可提供深度参数**。续航、电池能量、电池质量、整备质量等来自税收目录，可作为事实输出，但必须标注来源附件。
5. **所有参数事实必须标注来源附件**。例如："CLTC 续航 710km【来源：附件3 购置税目录】"。
6. **不得从型号推断商品名**。如果来源为附件1，CSA6492 是公告型号，不得映射；如果来源为附件3且包含 generic_model_name，则商品名可作为事实。
7. **跨附件注意事项**：不同附件的同一型号可能对应不同字段，需使用 `product_model` 作为 join key 合并。
8. **仍禁止结论**：价格、上市时间、智驾版本、配置高低配、市场威胁强度——所有附件均不提供。
