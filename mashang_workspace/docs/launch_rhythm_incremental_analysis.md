# 上市节奏增量贡献研究：预售–上市–权益结束

> 文档类型：研究方法与口径说明
> 数据快照：截至 2026-08-31（`order_data.parquet`）
> 研究对象：CM0 / DM0 / CM1 / DM1 / CM2 / LS9 / LS8 七个历史代际；DM2 作为当前对照

## 1. 研究问题

历史上各代际「预售小订 → 上市集中转大定 → 权益窗口兑现」的集中爆发式销售运营，对该车系累计销量带来多少**增量**，贡献**重要性**几何。

- 销量口径：**锁单为主**，交付/开票做稳健性检验
- 总量地平线：上市后 **12 个月**为主，**6 个月**对照
- 方法：**双轨** = 阶段占比法（重要性）+ 基线差值法（增量）
- 范围：仅智己 7 代际内部分析

## 2. 核心口径

| 概念 | 定义 | 来源 |
|---|---|---|
| 代际归属 | `series_group_logic`（CM0/1/2→LS6 家族，DM0/1→L6 家族，LS9/LS8 独立） | `shared/schema/business_definition.json` |
| 预售期 | `[start, end)`，小订收集期 | `time_periods.{g}.start/end` |
| 上市爆发期 | `[end, end+7d)`，上市集中锁单/转大定 | `time_periods.end` |
| 权益期 | `[end+7d, finish]`，上市权益窗口 | `time_periods.finish` |
| **上市节奏窗口** | `[start, finish]`（预售+上市+权益全程） | 三阶段拼接 |
| 总量窗口 | `[start, end+12M)`（含预售期），受 `as_of` 截断 | — |
| 零售口径 | `order_type ∈ {用户车, NaN}`；排除试驾车/员工/大客户/批售/享道/海外等全部非零售单 | `order_data.parquet` |

**说明**：
- 预售期 `order_type` 空值属正常业务状态（锁单前不区分订单类型），因此零售口径保留 NaN。
- 试驾车仅靠 `order_type='试驾车'` 即可干净识别（`product_name` 无额外信号），统一排除。

## 3. 方法

### 3.1 证据线 A — 阶段占比法（重要性）

每个代际按 `lock_time` 拆解到 4 段：

| 阶段 | 窗口 |
|---|---|
| 预售期锁单 | `[start, end)` |
| 上市爆发 | `[end, end+7d)` |
| 权益期 | `[end+7d, finish]` |
| 上市后常态 | `(finish, end+12M]` |

指标：
- **节奏窗口贡献率** = 节奏窗口（前 3 段合计）锁单 ÷ 总量窗口锁单
- 另输出上市首周/权益期锁单绝对量与占比（爆发集中度）

### 3.2 证据线 B — 基线差值法（增量）

**增量 = 节奏窗口实际锁单 − 基线日均锁单强度 × 节奏窗口天数**

基线（日均锁单强度）双轨：
- **基线1（上代成熟期）**：上一代际 `finish → finish+180d` 的日均零售锁单。仅用于家族内有上一代的代际（CM1←CM0，CM2←CM1，DM1←DM0）。
- **基线2（品牌自然）**：该代际 `end−180d → end` 全品牌零售日均锁单，**剔除落在任一上市活动窗口 `[start, finish]` 内的日期**，避免被他代际上市脉冲污染。

**增量贡献率** = 增量 ÷ 总量窗口锁单。首代（CM0/DM0）及独立车系（LS9/LS8）无上一代基线，仅用品牌基线；有双基线的代际取两者中位，报告区间。

**方法局限**：基线是反事实近似，无法识别"若不做上市运营用户何时会买"。负增量（DM1/LS8）表示窗口实际低于自然强度，不否定运营效果存在，只说明未跑赢自然流量。

### 3.3 证据线 C — 预售池转化追踪（机制）

- **预售小订池** = 预售期 `[start, end)` 内支付意向金、零售口径（排除试驾车）
- **转锁单** = 预售池中最终 `lock_time` 非空（含上市后转大定）
- **转交付** = 预售池中 `delivery_date` 非空
- **窗口内直接锁单** = 节奏窗口内锁单但无预售期小订

## 6. 主要结论（as-of 2026-08-31）

1. **上市节奏是车系放量的主引擎**：7 代际节奏窗口贡献率中位约 **35%**（12M 口径）；除弱代际外，基线差值法增量占总量 **10%–34%**，说明集中爆发式运营创造的是「额外量」而非「前置量」。
2. **最强案例 CM2（新一代 LS6）**：窗口贡献率 43.0%，增量约 19,689 单（占总量 33.9%），上市首周 11,287、权益期 13,658。
3. **弱代际警示 DM1（全新 L6）**：窗口实际锁单 5,215，低于上代成熟期自然强度，增量中位为负（约 -2,600 单）；DM0 增量占比亦仅 5.2%——L6 家族上市节奏的边际收益显著弱于 LS6 家族。
4. **LS8 窗口贡献率 68.7% 为观察期不足的统计假象**（总量仅 4.5 月），不可跨代际直接比较。
5. DM2 上市 3 天累计零售锁单 428（留存 423），尚处权益窗口早期，未纳入主对比。

## 7. 已知限制

- 基线与反事实是近似：不同基线选择会改变增量数值，结论以双基线区间呈现。
- 事件窗口内的量包含部分「无论如何都会发生」的自然购买，阶段占比法为上限估计。
- 早期代际（CM0/DM0/CM1）数据经过迁移，预售期 `order_type` 空值率高，小订口径基于意向金时间与试驾车排除，未做逐单人工核验。
- 交付/开票稳健性检验尚未在本版脚本中完整展开，作为后续扩展项。
