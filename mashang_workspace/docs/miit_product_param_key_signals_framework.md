# MIIT 公示车型参数解读：6 个关键信号框架

> 适用场景：用于解读工信部新车公示 / 公告车型参数，快速判断一辆车的产品定位、核心场景、竞争战场与潜在用户矛盾。
>
> 核心原则：不要把公告参数当成“参数大全”逐项复述，而是从参数中提取能解释产品意图的关键信号。

---

## 1. 方法定位

工信部公告 / 公示信息中的参数很多，但对产品经理最有价值的不是“谁更大、谁更重、谁功率更高”，而是：

1. 这辆车想进入哪个用户场景？
2. 它为了这个场景牺牲了什么？
3. 它与其他车型发生竞争时，真正的主矛盾是什么？

因此，车型参数解读应优先抓 6 个关键信号：

| 序号 | 关键信号 | 主要回答的问题 |
|---|---|---|
| 1 | 能源类型 | 用户买的是补能自由，还是纯电体验？ |
| 2 | 座位数 / 载客数 | 车辆进入的是个人、家庭，还是多人出行场景？ |
| 3 | 车身姿态与通过性 | 车辆是公路舒适取向，还是越野 / 户外能力取向？ |
| 4 | 车长 / 轴距 / 空间包络 | 车辆是否具备家庭大空间、二三排体验基础？ |
| 5 | 拖挂 / 载重 / 工具属性 | 车辆是否具备生活方式、户外、工具化能力？ |
| 6 | 智能化 / 感知硬件信号 | 车辆是否进入智能电动车叙事？ |

---

## 2. 六个关键信号详解

### 2.1 能源类型：决定用户心智入口

#### 关注字段

- 燃料种类
- 新能源类型
- 发动机 / 电机信息
- 储能装置种类
- 电池供应商 / 电池总成供应商
- 是否允许外接充电

#### 判断逻辑

| 能源类型 | 常见产品心智 | 典型用户问题 |
|---|---|---|
| 纯电动 | 电动化体验、智能化、城市 / 高速舒适出行 | 续航够不够？补能方便吗？智驾强不强？ |
| 插电混动 / 增程 | 长途无焦虑、补能自由、家庭全场景 | 能不能跑远？亏电表现如何？油耗如何？ |
| 燃油 / 非新能源 | 成熟可靠、成本、工具属性 | 可靠性、维护成本、渠道覆盖 |

#### 产品经理解读

能源类型不是一个技术字段，而是用户心智入口。  
同样是 SUV，纯电车型通常更容易进入“智能、舒适、家庭、科技”叙事；插混 / 增程车型更容易进入“远行、无焦虑、全场景、户外”叙事。

---

### 2.2 座位数 / 载客数：决定家庭场景强弱

#### 关注字段

- 额定载客（含驾驶员）
- 驾驶室准乘人数
- 座位数组合，例如 5、6、7、6/5

#### 判断逻辑

| 座位数 | 场景倾向 | 产品含义 |
|---|---|---|
| 5 座 | 个人 / 小家庭 / 户外 / 性能 / 越野 | 后排和后备箱空间更灵活，但不直接进入大六座战场 |
| 6 座 | 家庭多人出行 | 强二排体验，通常进入家庭旗舰 SUV 战场 |
| 7 座 | 多人承载 / 工具化 / 家庭备用 | 更偏“能坐下”，不一定等于高舒适 |
| 5/6 可选 | 同时覆盖家庭与非家庭用户 | 产品试图扩大覆盖面，但需判断主销版本 |

#### 产品经理解读

座位数是非常强的用户场景信号。  
如果一辆车具备 6 座版本，它往往不只是“多一个座位”，而是意味着产品要回答：二排舒适性、三排可用性、家庭成员照顾、儿童 / 老人出行、长途舒适等问题。

---

### 2.3 车身姿态与通过性：决定能力车还是舒适车

#### 关注字段

- 车高
- 接近角 / 离去角
- 前悬 / 后悬
- 轮胎规格
- 轮距
- 车身结构

#### 判断逻辑

| 信号 | 产品含义 |
|---|---|
| 高车身 | 更强通过性、户外姿态、越野感，但可能牺牲风阻和城市便利性 |
| 大接近角 / 离去角 | 明确的越野 / 非铺装路面能力信号 |
| 高扁平比轮胎 | 更强调越野、耐冲击、烂路适应性 |
| 大尺寸低扁平比轮胎 | 更强调视觉、操控、豪华感、公路属性 |
| 承载式车身 | 更偏城市 SUV / 家庭舒适 / 电动车平台 |

#### 产品经理解读

车身姿态比单纯的长宽高更重要。  
一辆车如果车高很高、接近角 / 离去角很大、轮胎偏越野规格，那么它的核心不是“空间大”，而是“能力冗余”。

---

### 2.4 车长 / 轴距 / 空间包络：判断家庭空间基础

#### 关注字段

- 长 / 宽 / 高
- 轴距
- 前悬 / 后悬
- 轮距
- 座位数

#### 判断逻辑

| 参数组合 | 产品含义 |
|---|---|
| 长车身 + 长轴距 + 6 座 | 明显进入家庭大空间 SUV 战场 |
| 长车身 + 5 座 | 可能强调大五座、后备箱、户外装载 |
| 短前后悬 + 长轴距 | 更有利于乘员舱空间 |
| 高车身 + 短轴距 | 更可能偏越野姿态，而非纯粹家庭空间 |

#### 产品经理解读

空间判断不能只看车长。  
车长、轴距、座位数必须一起看：

- 车长说明外部包络；
- 轴距说明乘员舱基础；
- 座位数说明空间分配意图；
- 前后悬说明空间与姿态之间的取舍。

---

### 2.5 拖挂 / 载重 / 工具属性：判断生活方式能力

#### 关注字段

- 准拖挂车总质量
- 额定载质量
- 总质量
- 整备质量
- 牵引专用装置
- 选装拖挂相关配置

#### 判断逻辑

| 信号 | 产品含义 |
|---|---|
| 明确拖挂能力 | 户外、露营、穿越、艇 / 房车 / 摩托拖挂等生活方式信号 |
| 带制动拖挂质量较高 | 更强的工具化与越野生活方式属性 |
| 选装牵引装置 | 厂家有意覆盖户外 / 拖挂用户 |
| 仅普通载客无拖挂信息 | 更偏城市家庭 / 常规 SUV 使用 |

#### 产品经理解读

拖挂能力不是边缘参数，而是很强的用户场景信号。  
它意味着车辆不只是“把人送到目的地”，还要承担装备、房车、露营、穿越等复杂生活方式。

---

### 2.6 智能化 / 感知硬件信号：判断是否进入智能电动车叙事

#### 关注字段

- 激光雷达
- 前 / 后 / 侧雷达
- 摄像头
- EDR
- ETC
- ABS 供应商
- 驱动电机功率
- 电池供应商

#### 判断逻辑

| 信号 | 产品含义 |
|---|---|
| 激光雷达 | 高阶智驾 / 智能旗舰叙事信号 |
| 多颗侧雷达 / 后雷达 | 城市辅助驾驶、泊车、侧向感知能力基础 |
| 多摄像头 | 感知硬件基础，但要结合智驾方案判断 |
| 仅 EDR / ETC / ABS | 更偏合规字段，不宜过度解读为智能化卖点 |

#### 产品经理解读

公告信息中的智能化字段通常不是完整配置表，但能提前暴露产品方向。  
如果出现激光雷达、侧雷达、后雷达等选装信息，这辆车在传播中大概率不会只讲空间和动力，而会进入“智能电动车”叙事。

## 3. 两类典型车型的主矛盾识别

### 3.1 能力车

典型信号：

- 插混 / 增程 / 可外接充电
- 高车身
- 大接近角 / 离去角
- 高扁平比轮胎
- 5 座或偏装载空间
- 明确拖挂能力
- 选装牵引装置

核心卖点：

> 我能带你去更远、更野、更不确定的地方。

主要用户需求：

- 长途无焦虑
- 户外 / 露营 / 穿越
- 非铺装路面能力
- 拖挂能力
- 装备承载
- 能力冗余带来的安全感

### 3.2 家庭智能车

典型信号：

- 纯电动
- 长车身 / 长轴距
- 5/6/7 座
- 承载式车身
- 大尺寸轮胎
- 激光雷达 / 多雷达 / 多摄像头
- 电机峰值功率较高

核心卖点：

> 我能让一家人在城市和高速场景里坐得更舒服、更智能、更体面。

主要用户需求：

- 二三排舒适性
- 家庭多人出行
- 城市 / 高速智能驾驶
- 纯电体验
- 豪华感与科技感
- 日常使用确定性

## 4. 参数解读流程

### Step 1：先判产品身份，不急着比参数

优先看：

1. 产品名称
2. 燃料种类 / 新能源类型
3. 座位数
4. 车身结构
5. 是否有越野 / 拖挂 / 智能化硬件信号

输出：

> 这辆车更像能力车、家庭车、性能车、工具车，还是综合型 SUV？

### Step 2：找参数中的“非普通信号”

重点找明显偏离常规城市 SUV 的字段：

- 车高特别高
- 接近角 / 离去角特别大
- 拖挂能力明确
- 轮胎规格偏越野
- 6 座 / 7 座
- 激光雷达 / 侧雷达
- 特殊电池 / 电机 / 发动机信息

输出：

> 哪些参数说明它不是普通 SUV？

### Step 3：判断为了核心场景牺牲了什么

产品参数的真正价值在于看取舍：

| 选择 | 可能获得 | 可能牺牲 |
|---|---|---|
| 高车身 | 通过性、视野、姿态 | 风阻、能耗、城市便利性 |
| 大接近角 / 离去角 | 越野能力 | 车内空间利用、造型比例 |
| 6 座 | 家庭多人出行 | 后备箱灵活性、车身成本 |
| 纯电 | 智能化体验、加速、静谧性 | 长途补能确定性 |
| 插混 / 增程 | 长途无焦虑 | 机械复杂度、纯电体验上限 |
| 大尺寸轮毂 | 视觉 / 豪华 / 操控 | 胎噪、舒适性、换胎成本、烂路适应性 |

### Step 4：提炼主矛盾

主矛盾不是“参数 A 比参数 B 多多少”，而是：

> 用户到底是在买什么确定性？

常见主矛盾包括：

- 能力冗余 vs 家庭确定性
- 长途无焦虑 vs 纯电智能体验
- 越野通过性 vs 城市舒适性
- 户外生活方式 vs 家庭多人出行
- 工具属性 vs 豪华科技属性
- 大空间 vs 高效率

## 6. 示例：能力车 vs 家庭智能车

### 6.1 能力车信号

如果一辆车具备以下参数：

- 插电混动
- 5 座
- 车高接近 1.9m 或更高
- 接近角 / 离去角明显较大
- 高扁平比轮胎
- 明确拖挂能力
- 选装牵引装置

则可初步判断：

> 这不是单纯的大 SUV，而是偏“能力车 / 户外车 / 越野生活方式车”。

关键不是它有多长，而是它能否提供：

- 远行能力
- 通过性
- 拖挂能力
- 户外装备承载能力
- 补能自由

### 6.2 家庭智能车信号

如果一辆车具备以下参数：

- 纯电动
- 车长超过 5m
- 轴距超过 3m
- 5/6 座可选
- 承载式车身
- 激光雷达 / 侧雷达 / 后雷达
- 大尺寸轮胎

则可初步判断：

> 这辆车更可能进入“家庭智能 SUV / 大六座新能源 SUV”战场。

关键不是它是否能越野，而是它能否提供：

- 家庭多人舒适出行
- 二三排空间体验
- 纯电智能化体验
- 城市 / 高速智驾
- 豪华感与科技感

---

## 7. 一句话原则

看工信部参数时，产品经理不要只问：

> 这辆车参数怎么样？

而应该问：

> 这些参数共同指向了什么用户任务？它为了这个任务做了什么取舍？它真正要打的是哪个战场？

最终结论应尽量落到一句话：

> 用户到底是在买“能力冗余”，还是在买“家庭确定性”。
