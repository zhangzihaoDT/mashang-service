# Market State V0.2 设计 —— Demand Pool → 控制结构 → 价格杠杆 三层漏斗

> 来源：`historical_opportunity_validation`（2024-03 冻结机会的 out-of-time 兑现检验）
> 状态：设计草案 v2（weights / thresholds 为初始值，需回测校准）

## 1. 为什么上一版设计不合理

V0.2 v1 草案把"Disruption Opportunity"定义为五因子加权，其中：
- `top1_fragility = 1 − TOP1 份额`（龙头占比低 → 易破局）
- `concentration_trend`（TOP3 集中度数值变化）

回测暴露两个错误：

1. **龙头占比高不等于不可破局**。SU7 进入的 20-25万 新能源轿车，TOP1=比亚迪汉 42.6%、TOP3 73.9%，照样验证期 +17.3%，SU7 自己卖出 10.2 万辆。`top1_fragility` 方向反了。
2. **集中度数值变化≠控制松动**。20-25万 轿车集中度数值反而在升（期末 MODEL 3 一家独大 48.8%），但榜首已从汉更替为 MODEL 3——"数值更集中"恰恰是**控制正在易主**的表现，不是稳固。

核心错误：把"集中度统计量"当成了"控制结构"的代理。真正要回答的是三个具体问题：

> 1. 这池子有没有需求（Demand Pool）？
> 2. 控制这个市场的 **TOP3 分别是谁**，他们**是不是正在失去控制**？
> 3. **价格是不是有效的攻击手段**？

## 2. 新框架：三层漏斗

```
Layer 1  Demand Pool（需求池）    → 有没有需求          （先找池子）
Layer 2  Control Structure（控制结构）→ 池子被谁管着、管得牢不牢（再看是谁在控制）
Layer 3  Price Lever（价格杠杆）  → 价格能不能作为攻击手段（最后看打法）
```

任一上游层不满足，下游层无意义。这是**漏斗**，不是正交两轴。

## 3. Layer 1：Demand Pool（需求池）

回答"这池子有没有需求"。主权重保留 `NEV 替代空间`（ρ=+0.72，验证支持）。

```
DPS = 0.7 · NEV_substitution_space + 0.3 · min(BEV/NEV, 1)
NEV_substitution_space = 1 − NEV_penetration
```

规模仅作**门槛**（S≥100万 / M≥30万 / L<30万），不进评分。`DPS < d_low` 直接排除（无需求池）。

## 4. Layer 2：Control Structure（控制结构）

回答"**TOP3 分别是谁**，他们**是不是正在失去控制**"。不再用集中度统计量，而是看具体在位者的状态：

| 信号 | 定义 | 方向 |
|---|---|---|
| top1_share_erosion | TOP1 份额流失：观测 12M 份额 − 期末月份额 | 正 = TOP1 正在被撼动 → CES 高 |
| top3_share_erosion | TOP3 整体份额流失：12M 份额 − 期末月份额 | 正 = 头部整体在失血 → CES 高 |
| leader_turnover | 榜首更替：12M 累计 TOP1 ≠ 期末月 TOP1 | 是 = 控制已易主 → CES 高 |
| challenger_presence | 挑战者：窗口末段（近 3 月）非 TOP3 车型增速 ≥25% 且挤入前 5 | 有 = 新玩家已开始侵蚀 → CES 高 |
| incumbent_aging | 在位者老化：TOP1 车型上市月龄 / 60 | 老 = 临近换代窗口 → CES 高 |
| incumbents_identity | TOP3 身份：是否同品牌系（≥2 属同一 brand） | 单一系垄断 = 攻击点集中，但需结合 erosion 判 |

```
CES = 0.25·top1_share_erosion + 0.25·top3_share_erosion
    + 0.20·leader_turnover + 0.15·challenger_presence + 0.15·incumbent_aging
```

关键修正：**不直接比较"TOP3 变成 TOP1"，而是比较"TOP3 分别是谁 + 各自的份额在流失还是稳固"**。SU7 市场 CES 高，不是因为集中度高，而是因为 12M TOP1=汉（老，2020 上市）期末已被 MODEL 3 反超、份额在流失、且 20-25万 轿车窗口末段已出现极氪007（增速 2349%）等挑战者。

## 5. Layer 3：Price Lever（价格杠杆）

回答"价格是不是有效的攻击手段"。V0.1 完全没有这一层。

| 信号 | 定义 | 方向 |
|---|---|---|
| price_headroom | (市场均价 − 价格带下沿) / 价格带宽度 | 高 = 下探空间大 → PLS 高 |
| incumbent_price_position | (TOP3 加权均价 − 市场均价) / 价格带宽度 | 正 = 在位者聚集在价格带上部，留出下探缝隙 → PLS 高 |
| price_sensitive_demand | 价格带下沿 30% 区间内车型的 12M 销量增速 | 正 = 低价需求已被验证 → PLS 高 |

```
PLS = 0.4·price_headroom + 0.3·incumbent_price_position + 0.3·price_sensitive_demand
```

## 6. Market State 合成

```
if DPS < d_low:                        → NO_DEMAND_POOL（无需求池，排除）
elif CES < c_high:                     → LOCKED_STABLE   控制没松动 → 价格再高也打不进去
elif PLS ≥ p_high:                     → PROVEN_UNDERSERVED  需求足 + 控制松动 + 价格有效
else:                                  → RIPE_WITH_BARRIER    需求足 + 控制松动，但价格不是杠杆（需产品力/品牌）
```

**关键修正（回测驱动）**：v1 草案的 `PRICE_SENSITIVE_ATTACK`（CES 低 + PLS 高）在回测中产生唯一 FP（30-35万 SUV 价格空间大但未扩容），确认了你的判断——**价格是建立在控制松动之上的攻击手段，不独立创造机会**。故 CES 是门槛（必要条件），PLS 只决定"攻法"（价格战 vs 产品力）。

机会集 = 非 LOCKED_STABLE / 非 NO_DEMAND_POOL，**不再有 v1"OPEN_RIPE 被排除出机会集"的矛盾**。

## 8. 回测计划与单期结果（2024-03）

复用 `historical_opportunity_validation` 两段式框架，替换分类器。

**单期结果（2024-03 冻结，2024-04~2025-03 兑现，扩容 = 新能源 12M 增速 ≥ +10%）：**

C_HIGH（控制松动门槛）敏感性（n=11 新能源市场）：

| C_HIGH | TP | FP | FN | TN | 精确率 | 召回率 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.15 | 9 | 0 | 1 | 1 | 100% | 90% |
| 0.20 | 8 | 0 | 2 | 1 | 100% | 80% |
| 0.25 | 7 | 0 | 3 | 1 | 100% | 70% |
| 0.30 | 5 | 0 | 5 | 1 | 100% | 50% |
| 0.40 | 4 | 0 | 6 | 1 | 100% | 40% |

**三个结论：**

1. **CES 是单调有效的排序信号**：所有 C_HIGH 下精确率恒为 100%（唯一未扩容的 30-35万 SUV 其 CES=0.03 恒被 LOCKED）。CES 越高越倾向扩容，无虚假机会。
2. **C_HIGH∈[0.15, 0.25] 时 recall 70-90% 且 precision 100%**，全面优于 V0.1（固定标签，precision 100% / recall 40%）。V0.1 只能输出一档判断，V0.2 的连续分数可调档。
3. **命中集合语义正确**：V0.2 识别的机会是"头部锁死但正在松动"的市场（25-30万轿车=MODEL3/汉易主、5-10万轿车=海鸥/缤果、10-15万 SUV、20-25万轿车=SU7 场景），正是 V0.1 漏掉的 FALSE NEGATIVE。

**回测暴露的边界（两类"扩容但非可攻击"市场）：**
- **在位者自身放量**（15-20万 轿车：E-QM5 份额 26%→49%）：市场在出量但控制没松动，CES 低——按框架正确判为 LOCKED_STABLE（不是好的攻击目标）。
- **产品结构内部替换**（5万以下：宏光MINI→熊猫mini，DPS=0.30 已饱和）：需求池已无新能源替代空间，应被 NO_DEMAND_POOL 排除。

## 8.5 Regime Dependence：同一指标在不同市场阶段经济含义不同

三期 point-in-time 的 Spearman 出现 **0.08 → 0.72 → 0.09** 的漂移。这不是权重调错，而是 **regime dependence**：`NEV 替代空间 = 1 − NEV渗透率` 这个变量，在不同渗透阶段表达不同的经济含义。

按两个可观察的 regime 代理分档（三期 37 个市场样本，替代空间 vs 后续新能源增速的 Spearman）：

**按渗透率水平分档（最直接）：**

| 渗透阶段 | n | NEV替代空间 ρ | NEV渗透率 ρ |
|---|---:|---:|---:|
| 低渗透率（<30%） | 10 | **0.600** | −0.115 |
| 中渗透率（30-50%） | 9 | **0.633** | 0.467 |
| 高渗透率（≥50%，成熟） | 18 | **0.094** | −0.001 |

**结论：替代空间只在渗透率 <50% 的市场有效（ρ≈0.6）；市场成熟后（≥50%）剩余燃油比例不再等于未来新能源增量（ρ≈0.09）。**

**按渗透速度分档（12M 渗透率变化）：**

| 渗透阶段 | n | NEV替代空间 ρ |
|---|---:|---:|
| 停滞/负 | 13 | 0.346 |
| 低速（0-15pp） | 12 | 0.427 |
| 加速（≥15pp） | 12 | 0.168 |

速度分档被高渗透率市场稀释（加速期含 2025 成熟市场），提示速度不是干净的 regime 代理；**渗透率水平 + 剩余燃油规模才是**。

**对 DPS 的修正（V0.3 方向，不动 V0.2 冻结公式）：**
- `NEV 替代空间` 仅作 **regime 门控有效**：渗透率水平 <50% 时保留主权重；≥50%（成熟）时切换到其他需求信号（市场规模/存量替换/产品周期）。
- 这也解释了 2025-03 期的 FP：DPS 里替代空间主权重在成熟市场失效，仍把替代空间大的市场判为机会。
- 不做"换权重"，而是**按 regime 切换变量组合**（规则门控，而非连续重加权）。

后续：
- 多期冻结（2023-03/2024-03/2025-03）网格搜索 C_HIGH/权重，防单期过拟合。
- 分层验证 DPS、CES、PLS 各自与扩容的 Spearman（V0.1 已验证 NEV 替代空间 ρ=0.72）。

## 8.6 V0.3 Hypothesis：从"替代驱动"切换到"下沉承接（Downshift Receiver）驱动"

> **定位**：以下为 V0.3 的研究假说与当前证据，**不是最终规则**。在通过独立验证前，不应直接进入 classifier 配置。
>
> **样本提示**：当前成熟期样本仅 **n=18**（分解后 n=14~17），属于**跨变量一致的初步证据**，待更多 freeze periods 验证后方可固化。

### 假说

`NEV 替代空间 = 1−NEV渗透率` 的经济含义随渗透 regime 变化，因此 DPS 的需求信号应做 **regime 切换**：

| regime | 需求信号 | 经济逻辑 |
|---|---|---|
| 未成熟（NEV 渗透率 <50%） | **替代空间**（低渗透=可释放空间） | 新能源替代燃油仍是主要增量来源 |
| 成熟（≥50%） | **Downshift Receiver（下沉承接市场）**，替代空间失效 | 剩余燃油不再等于增量；增长来自高价需求下沉后被低价带承接，承接增量由带内相对高端产品 + 控制松动主导 |

### 证据（三期 37 样本，Spearman vs 后续 12M 新能源增速）

**① 两侧解释变量差异（regime 切换的直接证据）：**

| 变量 | <50%（n=19） | ≥50%（n=18） |
|---|---:|---:|
| NEV替代空间 | **0.614** | 0.094 |
| CES（控制松动） | 0.254 | 0.356 |
| 市场规模 | −0.077 | 0.110 |
| 产品更新（新品数） | 0.180 | 0.072 |

**② 成熟期（≥50%）驱动变量分解（四类候选，按 ρ 降序）：**

| 变量 | n | ρ |
|---|---:|---:|
| TOP3 价格变化%（混合） | 18 | 0.470 |
| 新品/老品价格比 | 18 | 0.410 |
| CES（控制松动） | 18 | 0.356 |
| 在位 TOP3 涨价%（同批车型真实提价） | 17 | 0.311 |
| TOP3 更替价差%（新品−被换） | 14 | 0.297 |
| 场景总需求池 | 18 | 0.094 |
| 最大新车型销量 | 18 | 0.077 |
| NEV 替代空间（对照） | 18 | 0.094 |

### 假说解读（方向性判断，待验证）

1. **成熟期增长与"本价格带上沿产品走强 + CES 松动"相关**，但存在**两种互斥解释，必须查清**：

   - **Premiumization（价格段内部产品升级）**：原来在本带的消费者向上选择更贵更好的产品（同带内 15-20万 → 18-20万）。
   - **Price-band migration（价格带迁移/高价需求下沉）**：更高价格带需求下沉到本带（20-25/25-30万 → 15-20万），同时本带承接增量的是靠近上沿的产品。

   两者的可观察组合高度相似（本带扩容 + 本带 TOP3 价格上涨），但经济含义相反。

2. **判别方法（价格带迁移研究，已立项为 `price_band_migration` spec）**：把连续价格带放一起看，并计算 **Price Gravity = Σ(价格带中值 × 销量) / 总销量**。若出现"本带扩容 + 本带 TOP3 价格升 + **整体价格重心下降** + 上一档萎缩"，则更可能是**高价需求下沉**（消费降级中的承接者），而非消费升级。

### Downshift Receiver（下沉承接市场）：概念与操作化定义（V0.3 核心概念）

一个价格带成为"下沉承接市场"，**需同时满足三个必要条件**：

| # | 条件 | 操作化 | 数据来源 |
|---|---|---|---|
| 1 | 本带份额明显上升 | `share_delta_pp ≥ +1.0`（跨 freeze） | price_band_migration |
| 2 | 整体 Price Gravity 下移 | `gravity_delta < 0` | price_band_migration |
| 3 | 上一级价格带承压 | 上一档份额或销量下降 | price_band_migration |

**再叠加两个增强信号**（决定优先级，非必要）：

| 信号 | 操作化 | 经济含义 |
|---|---|---|
| E1 CES 高 | `CES ≥ C_HIGH` | 旧 TOP3 正在松动，增长能被别人拿走 |
| E2 本带 TOP3 靠上沿 | `top3_price_position ≥ 0.5` | 消费者不是追求最低价，而是"降一档预算后仍追求更好的产品" |

**分级**：
- **Strong Receiver**：三必要条件 + E1 + E2（最高优先级）
- **Receiver**：三必要条件 + E1 或 E2
- **Weak Receiver**：仅三必要条件

### V0.3 成熟期管线（替换"产品升级 + CES"）

```
成熟期（NEV 渗透率 ≥50%）
  → ① 判断是否价格带下沉（整体 Price Gravity 下移）
  → ② 在参与下沉的价格梯度里找 Downshift Receiver（份额升 + 重心降 + 上一档承压）
  → ③ 看 CES 是否松动（增长能否被别人拿走）
  → ④ 看本带上沿产品是否占优（降档求好，而非纯低价）
  → 标记为成熟期机会（Strong/Receiver/Weak）
```

3. **临时结论（V0.3 输入，已含价格带迁移判别）**：`price_band_migration` 研究（三期横截面）显示新能源轿车/SUV 价格重心分别下降 **2.4万 / 2.7万**（整体重心下移），判别为：
   - **轿车新能源 = 低段承接 + 内部高端化**（5-10万扩容 +15pp 且该带 TOP3 上移，但整体重心降）——即 **Strong Receiver 候选**（含 E2：带内 TOP3 靠上沿）；
   - **SUV 新能源 = 高价需求下沉**（10-15万扩容 +31pp，TOP3 未上移）——**Receiver 候选**（E2 不满足）。
   
   故成熟期"本带 TOP3 变贵 + 扩容"在数据上更可能是**消费降级中的赢家**，而非同带消费升级。V0.3 成熟期需求信号应转向 **Downshift Receiver（下沉承接市场）管线 + CES 松动**，而不是"产品升级驱动"。

### Downshift Receiver 三期实证（2024-03 / 2025-03 冻结）：结构性信号天花板

对三期数据实现 Downshift Receiver 判定（`downshift_receiver_screen.py`），并检验被识别价格带未来 12M 扩容：

| 判定 | n | 命中率（未来12M扩容） |
|---|---:|---:|
| 全样本基准 | 171 | 33% |
| 新能源全样本 | 81 | **48%** |
| Receiver（三必要条件） | 18 | **17%** |
| 非 Receiver | 153 | 35% |

**结论（结构性信号天花板）：**
1. **必要条件是"同步/事后信号"，预测力反向**：份额升 + 重心降 + 上一档承压描述的是"下沉已发生"，承接完成后往往没有更多增量（17% < 基准 33%）。
2. **CES 是唯一有正贡献的信号**，但增益有限（新能源内 CES 高 43% vs 新能源基准 48%）；TOP3 位置无判别力。
3. **决策：接受成熟期"结构性预测"天花板**——成熟期扩容主要受单点冲击（SU7 型）驱动，结构性变量（渗透率/集中度/价格重心/下沉承接）的预测力到顶。

### 已知边界与未验证项

- 样本量小（成熟侧 n=18，分解后 n=14~17），ρ 的置信区间宽。
- "价格上行→增长"可能是**同步信号**而非先行信号（观测窗口价格变化 vs 后续增长，方向待因果性检验）。
- **Premiumization vs Price-band migration 已初步判别**：`price_band_migration` 显示新能源轿车/SUV 重心下降、低段承接（详见假说解读第 2、3 条）；但该判别基于三期横截面的启发式组合，阈值（份额/增长/重力显著性）待更多 freeze 期校准。
- 成熟期增长仍可能有未捕捉变量（政策、大单品爆发在验证窗口内才出现）。
- 需用 holdout 期（如 2025-03 冻结→2025-04~2026-03 验证）独立检验切换后的 DPS 能否消除 2025 期 FP。

## 8.7 V0.3 Runtime 架构：Market State × Shock Detector

结构性预测天花板（8.6）之后的 Runtime，应拆成**两个职责独立的组件类**，而不是一个单一评分模型。

### 两类组件

| 组件类 | 回答的问题 | 性质 | 信号来源 |
|---|---|---|---|
| **Market State** | 这个市场**现在是什么状态**？ | 描述性（环境是什么样） | 结构性：渗透率/控制结构(CES)/价格重心/下沉承接 |
| **Shock Detector** | 有没有**东西可能打破**这个成熟市场？ | 预测性（有没有推动者） | 单点：放量新品/性价比攻击/份额侵蚀 |

### 职责边界

- **Market State**：描述环境。DPS/CES/PLS 三层漏斗、regime（渗透阶段）、Downshift Receiver（下沉承接，作为**同步状态描述**而非预测器）。结构性信号预测力已到顶（8.6），但仍刻画"环境是否允许"——尤其 **CES 松动 = 增长能被别人拿走**。
- **Shock Detector**：识别推动者。检测"正在启动的爆款"（Breakout Entry），不回答市场结构，只回答"有没有一台车可能打穿它"。

### 协同（成熟期判断管线）

```
成熟期机会 = Market State 允许（CES 松动，环境可被打破）
          × Shock Detector 在场（观测到 Breakout Entry，实际有推动者）
```

两者缺一不可：CES 高但无冲击者在场 → 环境允许但没动静；冲击者在场但 CES 低 → 有推动者但被在位者锁死。

### Shock Detector 核心概念：Breakout Entry（放量新进入者）

一个新品成为"冲击者"的早期信号（观测窗口可观察）：

| 信号 | 定义 | 说明 |
|---|---|---|
| 爬坡速度 | 上市后前 3 个月月均上险量爬坡（第3月/首月） | 爬坡越快，冲击越强 |
| 进入速度 | 进入该价格带 TOP10/TOP5 的月数 | 越快越强 |
| 性价比攻击 | 新品 weighted_tp 相对同带在位者 / 价格带下沿 | 低价高配 = 攻击性强 |
| 份额侵蚀 | 新品对在位 TOP3 份额的挤压 | 在位者失血越快，冲击越实 |
| 末段增长 | 观测窗口最近 3-6 个月新品销量增速 | 历史已捕获：极氪007 +2349%、银河E8 +1927%、宋L +696% |

**验证设计（复用两段式框架）**：观测窗口识别候选冲击者 → 验证窗口看该新品是否成为爆款 + 该市场是否扩容。核心指标 = **冲击者识别精度**（识别的冲击者中最终成为爆款的比例，对照随机新品）。

**数据来源**：model_monthly（新品销量爬坡/进入排名/份额侵蚀）+ price_segment_monthly（价格位置）。

### Shock Detector 实证与 2×2 增量检验（2024-03 / 2025-03 三期）

**早期信号（末段月均≥2000 + 爬坡 + 进 TOP10）的命中率（验证窗口爆款）：**

| 分级 | n | 命中率 |
|---|---:|---:|
| Shock Candidate | 66 | **47.0%** |
| Strong | 8 | 37.5% |
| 全部新品 baseline | 995 | 7.9% |

**2×2 增量检验（Shock × CES → 爆款率）：**

| | CES 低(<0.2) | CES 高(≥0.2) |
|---|---|---|
| Shock 否 | 2.1%（n=96） | 2.9%（n=273） |
| Shock 候选 | **64.7%**（n=17） | 48.9%（n=45） |

**结论：**
1. **Shock 是绝对主角**（主效应 ~20 倍）。
2. **CES 对 Shock 无增量，且方向反**（候选内 CES 低 64.7% > CES 高 48.9%）——Market State 的 CES 维度在成熟期冲击预测上没有资格留下。
3. **机制（CES 反向）**：CES 高 = 群雄逐鹿（挑战者 0.82 / 榜首易主 0.62），冲击者被淹没在群体里、份额互相稀释；CES 低 = 在位者稳但真空（挑战者 0 / 榜首稳），单点强冲击者进入后无人阻挡、直接独占成爆款。

**修正 V0.3 机会逻辑**（不是 `Market State × Shock` 相乘）：

```
成熟期机会 = 真空市场（CES 低、无挑战者）× 单点强冲击（Shock Candidate）
CES 不是增强因子，而是 Shock 命中的调节条件（真空让冲击者独占）
```

**边界**：CES 低侧 n=17，命中率置信区间宽，需更多 freeze 期验证"真空×冲击"模式。

## 9. 开放问题
