| 项 | 旧实现实测耗时 |

真实原因：旧 `main()` 中三张图的计算函数与绘图函数**全部错配**：

| `main()` 计算 | 实际调用的绘图函数 |
|---|---|
| `compute_ls6_reev_metrics` | 图 4（LS8 66）的 build |
| `compute_ls8_66_metrics` | 图 5（增程配置）的 build |
| `compute_reev_product_breakdown` | 图 3（LS6 增程）的 build |

绘图函数拿到不匹配的 DataFrame 后在新结构上反复渲染/抛错，造成挂起；旧 HTML 中这三张图实际错位或被静默跳过。
