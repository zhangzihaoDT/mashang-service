# 研究报告：上市节奏（预售–上市–权益结束）对车系销量的增量贡献

> 文档类型：研究报告（结论沉淀）
> 数据快照：as-of 2026-08-31（`order_data.parquet`，零售口径）
> 口径与方法细节：见 `docs/launch_rhythm_incremental_analysis.md`
> 报告生成：`python mashang_workspace/research_scripts/launch_rhythm_incremental_analysis.py --html`

## 一、研究目标

评估历史上各代际「预售小订 → 上市集中转大定 → 权益窗口兑现」的集中爆发式销售运营，对该车系累计销量带来多少**增量**，贡献**重要性**几何。

即回答：**预售–上市–权益结束这套上市节奏，对业务的销量贡献到底有多大、是否值得投入。**

- 销量口径：**锁单为主**，交付/开票做稳健性检验
- 总量地平线：上市后 **12 个月**为主，6 个月对照
- 研究对象：CM0 / DM0 / CM1 / DM1 / CM2 / LS9 / LS8 七个历史代际；DM2 作为当前对照

## 二、研究方案

双轨方法：

1. **证据线 A — 阶段占比法（重要性，描述性）**：按 `lock_time` 把每个代际拆解到 预售期 / 上市爆发 / 权益期 / 常态期，计算节奏窗口 `[预售start, 权益结束finish]` 内锁单占总量（`[start, end+12M]`）比例，衡量上市节奏在总量中的占比。

2. **证据线 B — 基线差值法（增量，反事实）**：用基线日均锁单强度推断"不做上市运营时窗口内本应有的量"，实际值减去即为增量。

3. **证据线 C — 预售池转化追踪（机制）**：预售小订池 → 上市转大定/锁单 → 最终交付的转化链，验证预售池是放量的核心载体。

**关键口径**：零售 = `order_type ∈ {用户车, NaN}`（预售期空值属正常状态）；排除试驾车/员工/大客户/批售等全部非零售单。

## 四、核心结论（as-of 2026-08-31，零售口径，12M 窗口）

### 4.1 上市节奏是放量主引擎，不是补充

7 代际节奏窗口（预售→上市→权益结束）锁单贡献率中位 **35%**；除弱代际外，基线差值法增量占总量 **10%–34%**——集中爆发式运营创造的是「**额外量**」而非「**前置量**」。

### 4.2 各代际表现（窗口贡献率 / 增量）

| 代际 | 窗口贡献率 | 增量（中位） | 增量占总量 |
|---|---|---|---|
| **CM2（新一代 LS6）** | **43.0%** | **+19,689** | **33.9%** |
| LS9 | 38.5% | +5,518 | 27.6% |
| CM0（LS6 初代） | 35.0% | +10,963 | 28.6% |
| DM1（全新 L6） | 27.5% | **−2,617** | −13.8% |
| DM0（L6 初代） | 23.3% | +1,412 | 5.2% |
| CM1（LS6 全新） | 18.2% | +4,304 | 10.9% |
| LS8 | 68.7%* | −1,110 | −10.7% |

> \* LS8 观察期仅 4.5 月，总量窗口未满导致占比虚高，**不可跨代际直接比较**。

### 4.3 家族差异显著

- **LS6 家族**（CM0/CM1/CM2）：增量合计 **+34,956**，占家族总量 **25.7%**——上市节奏贡献突出。
- **L6 家族**（DM0/DM1）：增量合计 **−1,206**（−2.6%）——**DM1 负增量是主因**，L6 家族上市节奏的边际收益明显弱于 LS6 家族。

### 4.4 DM2 当前对照

上市 3 天累计零售锁单 **428**（留存 423），尚处上市节奏窗口（权益结束 2026-10-31）早期，未纳入主对比。

## 五、增量计算逻辑（证据线 B）

核心是**反事实**：估算"假设没有这套上市运营，按当时的自然流量强度，窗口内本应有多少锁单"，再用实际值减去它。

```
增量 = 节奏窗口实际锁单 − 基线日均锁单强度 × 节奏窗口天数
```

- **节奏窗口** = `[预售start, 权益结束finish]`（DM1 为 2025-04-18 ~ 06-15，共 58 天）
- **基线日均双轨**，取增量中位：
  - **基线1** = 上一代际（DM0）成熟期 `finish→+180d` 日均零售锁单
  - **基线2** = 上市前 180 天全品牌自然日均（**剔除各上市活动窗口日期**）
- 正增量 = 运营创造了超额量；负增量 = 窗口实际量低于自然强度预期

### 5.1 DM1 为什么是负增量

| 项 | 值 |
|---|---|
| 窗口实际锁单 | **5,215**（日均仅 89.9/d）|
| 基线1 预期（DM0 成熟期 216.45/d × 58d） | 12,554 |
| 基线2 预期（品牌自然 135.04/d × 58d） | 7,832 |
| 增量1 / 增量2 | −7,339 / −2,617（中位 **−2,617**）|

两个基线预期的"自然锁单"都比 DM1 窗口实际量高，所以增量必然为负。根因拆两层：

1. **DM1 窗口绝对量确实弱**：5,215 是 7 代际最低（DM0 6,314 / CM1 7,196 / CM2 24,953），日均 89.9 连品牌自然水平（135/d）都不到——上市爆发（2,980）+ 权益期（2,232）加起来没形成超出日常的脉冲。
2. **基线参考偏高**：基线1 用的是 DM0 成熟期 216/d，那是 L6 初代巅峰，作为 DM1 的"自然强度"参照系统性高估预期；但即使换成品牌基线（135/d），仍有 −2,617。

### 5.2 正确解读（两点限定）

- **负增量 ≠ 上市运营无效**。它只说明"窗口内量未跑赢当时的自然流量水平"，不能推出"不做预售效果一样"。运营可能仍把量从 5,000 拉到 5,215，只是这个幅度不足以超越基线。
- **基线对弱代际更敏感**。当一个代际本身走弱（产品力/价格/竞争环境不如上代）时，用上代巅峰期作基线会放大负值。DM1 的负增量中约一半来自基线1 偏高（−7,339），一半来自自身偏弱（品牌基线仍为 −2,617）。
