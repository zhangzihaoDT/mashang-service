# archive 材料清单

> 用途：登记 `mashang_workspace/docs/archive/` 全部材料，**按车型归档**。新增文件须在对应车型章节补登（文件名 + 类型 + 代际 + 说明）。
> 代际口径（源自 `shared/schema/business_definition.json` → `model_series_mapping`）：
> - **LS6**：`CM0` → `CM1` → `CM2` → `CM3`（`CM3` = 全新一代 LS6 / 内部称 M3）
> - **L6**：`DM0` → `DM1` → `DM2`（`DM2` = L6 M2）
> 别名：「新款 LS6」= `CM3`；「现款」= `CM2`/`T1`。依据 `CM3_升级点.md`。
> 更新：2026-09-17

## 登记规则

1. 新文件先按车型归入 LS6 / L6 / 通用（非车型）章节，再写「类型 + 代际 + 说明」。
2. 图片/素材目录挂在所属正文材料下，单独登记一行。
3. 派生分析（由其他材料归纳）标注来源；规格级缺口登记在「已知缺口」。
