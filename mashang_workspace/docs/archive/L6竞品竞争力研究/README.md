## 研究结论

**智己 L6 是这张表里"全能度"与"性价比"双料第一的产品。**

回填 L6 官方指导价（Max 20.99 / ProMax 22.79 / Ultra 26.99 万）后，13 个 SKU 四维等权计分：

- **总分前四占三席**：L6 Ultra 69.8 断层第一；SU7 Max 54.9 第二；L6 ProMax 54.8、L6 Max 50.0 分列三、四。
- **得分/万前三全包**：L6 2.38~2.59 vs 竞品最高 1.96——不是以价换量，同分数下比 SU7 Max 便宜 3.4 万。
- **竞争力画像**：底盘 + 座舱双冠（后轮转向/线控制动/转弯半径全表独有；中控 27.1 寸/副驾屏/冰箱/二排按摩独有）；三电中游（充电速度 2.07~2.5C 垫底）；**智驾基础款算力 254T 是最大软肋**（竞品 700~750T，表注 Thor 700 为 OTA 升级项）。

**竞品偏科盈利位**：极氪 007 = 三电性能王（900V/6C/905km 全表第一）但底盘座舱垫底；P7/阿维塔 = 智能标签党（阿维塔智驾 96.6 全表第一）；小米 SU7 = 靠品牌，得分/万 1.41~1.81 全表最低档。

## 计分口径

- **维度权重**：三电 / 底盘 / 座舱 / 智驾 各 25%（等权），组内各指标等权。
- **归一化**：各指标按 13 个 SKU 全量 Min-Max 归一化，方向感知（充电时间/加速/电耗/转弯半径 = 越小越好取反）。
- **价格**：L6 为官方指导价（上市权益价更低：199,900 / 217,900 / 259,900）；竞品为对比表 MSRP（万元）。
- **空值处理**：对比表中空单元格按"无"处理（如 SU7 Pro 无 HUD/副驾屏/冰箱，座舱得分 1.0 系数据所致）。
- **主观指标**：底盘「空悬」档位化（标配 1.0 / 选配 0.5 / 无 0）、「卡钳」「智驾车系」为仲裁评分，见脚本内注释。
