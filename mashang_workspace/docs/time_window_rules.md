# Time Window Rules — 时间窗口规则

> 来源: operators/time_windows.py (650 行时间解析引擎)

## 通用规则

所有时间窗口统一按 **左闭右开 `[start, end)`** 执行过滤：
- `lock_time >= start` AND `lock_time < end`

## 常用时间窗口

| 自然语言 | 解析规则 | 示例 |
|----------|----------|------|
| 昨天 | T-1 全天 | `2026-06-10` ~ `2026-06-11` |
| 今天 | T 全天 | `2026-06-11` ~ `2026-06-12` |
| 最近 N 天 | T-N ~ T (不含T) | 近7天 = T-7 ~ T |
| 最近 N 周 | 转天数: N×7 | 近2周 = 14天 |
| 最近 N 个月 | 转天数: N×30 | 近3个月 = 90天 |
| 本周 | ISO 周一 ~ 今天 | |
| 上个月 | 上月1日 ~ 本月1日 | |
| 本月 | 本月1日 ~ 下月1日 | |
| 今年 | 当年1月1日 ~ 下年1月1日 | |
| YYYY年MM月 | 该月1日 ~ 下月1日 | 2026年5月 |
| YYYY年 | 当年1月1日 ~ 下年1月1日 | 2026年 |
| YYYY-MM-DD | 该日 ~ 次日 | |
| YYYY/MM/DD | 同上 | |
| MM月DD日 | 自动补当年 | 5月17日 → 2026-05-17 |
| N月N日~N月N日 | 范围解析 | 5月1日~5月10日 |
| 累计/累积 | end 截断为 today+1d | YTD 语义 |
| 上市以来 | 按 series 取 time_periods.end 作为起点 | LS8 → 2026-04-16 |

## Cohort 时间概念

| 术语 | 含义 |
|------|------|
| cohort | 按 assign_date 分组的一批用户 |
| day_after (D) | 分配后的第 N 天 |
| D0 | 分配当日 |
| D7 | 分配后 7 天 |
| D14 | 分配后 14 天 |
| D30 | 分配后 30 天（成熟基准） |
| D60 | 最大观察窗口 |

## 时间解析优先级

1. 显式日期范围（`~` / `到` / `至`）
2. 具体日期（`2026年5月17日`）
3. 相对时间（`近30日` / `昨天` / `本周`）
4. 累计语义（`累计` / `累积`）
5. 上市时间推断（按 series 匹配 time_periods）

## 特殊规则

- `近N个`：支持 `近2个月` / `近3周` 等含"个"的表达
- 年正则：`2026年` 后面跟 `月均` 时不算月份
- 数字范围：`~5月17日` 作为范围而非拆分
- 累计查询自动删除时间维度（累计时不再按天/月分组）
- 同比目标年：`2026累计同比2024` 正确偏移 -2 年
