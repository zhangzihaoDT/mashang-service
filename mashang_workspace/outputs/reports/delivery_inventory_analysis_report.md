## 库存定义

本报告采用"物理位置 × 业务状态"二维分类模型：

```
物理库存 = 仍位于中央物流体系（VDC / VDC→DC在途 / DC内）
经销商责任库存 = 已离开DC 且 属于经销商模式
历史直营 = 已离开DC，无 Dealer Attribute，但订单完整

库存判定 = 物理位置 + 订单状态 + Dealer模式 共同决定
```

所有数字均基于事件时间字段的事实判定，时序违反记录仅标记不重分类。

### 核心库存监控指标：国内DC在库_未开票

**口径：** 物理位置=DC内 + bloc_name不为上汽国际/海外（剔除出口） + invoice_upload_time为空（未开票）

**含义：** 国内经销商端交付中心中，已到店、未开票的实物库存，反映当前可售现车供给水平。

> 注意：DC（交付中心）本质为经销商接车节点，DC内库存归属经销商端而非总部。
