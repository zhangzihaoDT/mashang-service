# 智己各系生命周期锁单量阶段划分

> 数据快照：`dataset/order_data.parquet`（截至 **2026-09-01**）
> 口径：零售（`order_type ∈ {用户车, NaN}`，排除试驾车）；锁单 = `lock_time` 非空 COUNTD(order_number)；代际归属按 `business_definition.json` 的 `series_group_logic`
> 生命周期窗口（本代 `end`（上市）→ 右界）：
> - 有换代车型（CM0/CM1/CM2）：右界 = 换代车型 `end` - 1
> - 无换代车型（LS8/LS9，或 CM2 换代车型尚未上市）：右界 = as-of 前一日（"至今"）
> as-of = **2026-09-02**，"至今" = **2026-09-01**
> 方法：7 日周块聚合 → DP 分段常数分割，**统一 k=5**；周段边界映射回日
> 脚本：`research_scripts/l6_lock_lifecycle_stages.py`

**核心结论**

1. **CM 家族规模递进**：CM0 → CM1 → CM2 生命周期均为约 350 天，累计锁单 38k → 39k → **58k**。CM2 上市冲量峰日均 **1,019.6**，约是 CM0（540）/ CM1（569）的 2 倍，规模量级明显跃升。
2. **CM0/CM1 生命周期完整**：均以"上市冲量峰 → 中间平台/回落 → 换代前低迷期"收尾，末段日均分别 25.7 / 34.8，清洗完整。
3. **CM2 仍处进行中**：右界用"至今"（换代 CM3 未上市），当前处在 **103.1/日的平稳段**（2026-03-04 至今，占累计 32.2%），显著高于前两代同期的换代表现，说明 CM2 生命周期中后段支撑更强。
4. **LS8 处于上市后快速回落通道**：4 月上市冲量 350.4/日（占至今累计 47.3%），随后步降，当前 28.7/日，尚在早期回落区间，未进入平台稳定。
5. **LS9 处于低量平台震荡**：冲量峰 461/日后快速回落，当前 25.6/日低位，尚未见回升；作为无换代车型，LS9 生命周期仍在开放中。

| 维度 | CM0 | CM1 | CM2 | LS8 | LS9 |

**共性规律**

- 所有代际都呈现"上市冲量峰 → 高位回落 → 平台/回升 → （低位）延续"的序列，冲量 + 首段回落合计贡献累计锁单的 **40%~48%**。
- 已收尾代际（CM0/CM1）末段换算前低迷期日均落在 **25~35/日**，可作为判断"换代前滑落"的参考区间。
- 在售代际（CM2/LS8/LS9）末段日均 **25~103/日** 差异大：CM2 是强延续（103），LS8/LS9 是低量（26~29）。

## 八、方法说明与局限

**方法**
- 锁单口径 = `order_data.parquet` 零售行，`series_group_logic` 归属代际。
- 逐日 → 7 日周块 → 周序列 DP 分段常数分割，**统一 k=5**（`--n-segments` 可覆盖；`--auto-select` 退回 BIC+容差）。
- 生命周期右界：有后继代（SUCCESSORS: CM0→CM1→CM2→CM3、DM 链）取后继 `end`-1；无后继（LS8/LS9）或后继尚未上市（CM2，CM3 2026-09-26 上市）时截断到 **as-of 前一日（"至今"）**，末段标"当前阶段(至今)"。
- 锚点：`end`（上市）、`finish`（权益结束）、换代 `end`-1 / 至今。

**局限**
- 阶段边界按 7 日周块粒度，可能比真实业务事件（促销/权益节点）滞后数日。
- 在售代际（CM2/LS8/LS9）末段为截断样本，后续仍可能演化出新的回升/平台。
- CM0 数据到 2024 年即收尾，期间促销口径变化可能影响段 4 单日值。
